(`.gitignore`의 `*.png`/`*.jpg` 규칙에서 이 폴더만 예외로 열어 뒀다).

| `card-b/web/*.webp` [2026-09-05] | 타로 카드 그림 10장 + 테두리 1장 (`CARD_B_DIR`, 카드 만들 때만 받는다) | 800×993 / 900×1612 | 그 자리가 빈 하지색 판으로 그려진다 — 카드 생성은 멎지 않는다 |
| `card-b/*.png` | 위 축소본의 **원본**(1856×2304, 테두리 1536×2752). 앱은 읽지 않는다 | — | 축소본을 다시 만들 때 필요하다 |

> **★ 이름에 판(版)이 붙어 있다.** `og-image.jpg` 하나로 다섯 번을 갈아 끼웠더니 카카오가
> **URL 단위로 그림을 캐시**해 스크랩 캐시를 지워도 옛 그림이 계속 떴다(2026-08-31).

## 배경을 바꾸려면

`card-bg.jpg` **파일 하나만 바꿔 넣으면 된다.** 코드는 손대지 않는다 — 경로가
`index.html`의 `CARD_BG_SRC` 상수 한 곳에만 적혀 있고, 그림은 `cover` 방식으로
카드 크기에 맞춰 잘려 들어간다(비율이 달라도 늘어나지 않는다).

조건 두 가지:

- **글자·워터마크가 없을 것.** 카드 글은 앱이 그 위에 그린다. 그림에 글이 있으면 겹친다.
- **어두울 것.** 글자 깔개(위아래로 옅어지는 검정 그라디언트)를 얹지만, 밝은 그림 위에서는
  흰 글씨가 읽히지 않는다.

## `../og-v4.jpg` — 생성 아트가 아니라 **화면 캡처**다

[2026-08-30] 공유 미리보기는 **앱 화면을 그대로 찍은 것**으로 바뀌었다(생성 아트 폐기).
그림이 예쁜 것보다 **이 앱이 무엇인지 보이는 것**이 미리보기의 일이기 때문이다.

**★ 다시 찍을 때 지켜야 할 것 — `my-data.js`가 없는 사본 + 앱 내장 데모 시드에서만 찍는다.**
이 파일은 공개 저장소에 커밋되므로 실명이 한 글자라도 들어가면 되돌릴 수 없다.
찍은 뒤에는 **그림 안의 글자를 전수 확인**한다.

[2026-08-31 · og-v4] 구도를 「은하 조망」에서 **성계 근접**으로 바꿨다 — 항성 「나」의 지름이
프레임 세로의 30.9%(194.5px)이고, 고리를 두른 「선배」와 「친구」가 이름표와 함께 든다.
멀리서 잡으면 미리보기 축소(약 600×315)에서 이름표가 안 읽혀 "무엇인지"가 안 보인다.
지금 그림의 글자는 여섯 개다 — 나 / 丙 · 불타는 행성 / 선배 / 壬 · 물의 행성 /
친구 / 乙 · 숲의 행성. 전부 데모 시드의 관계어와 일간 별칭이고 **실명은 0건**이다.

찍는 법은 캔버스를 직접 읽는 것이다 — DOM 크롬(패널·버튼·시트)이 자동으로 빠진다:
`renderer.setSize(1200,630,false)` → `composer.render()` → `renderer.domElement.toDataURL()`.

카메라는 [2026-08-31] **은하 조망(`cam.r=110`)에서 성계 근접으로 바꿨다.** 항성에서
r=25만큼 떨어져, 항성과 이웃 행성을 잇는 선이 화면에서 수평이 되도록 `camera.up`을
`시선 × 그 선`으로 잡고, 두 천체의 중점을 바라본다. 항성 지름 = 2R·(H/2)/(r·tan(fov/2))이므로
r=25에서 194.5px = 세로의 30.9%다(25~35% 목표 구간 안).
궤도 위상은 `t`를 고정해 결정론으로 만든다 — 안 그러면 찍을 때마다 이름표가 서로 겹치거나
프레임 밖으로 잘린다(실제로 위상 10·34·46에서 각각 잘렸다. 채택 위상은 18).
**탭이 뒤에 있으면 rAF가 멈춰 카메라가 수렴하지 않는다** — `t`를 직접 밀며
`simulate(); camTick();`을 수백 번 돌린 뒤 찍을 것(CLAUDE.md "3D 화면 측정 함정").
품질은 JPEG 0.88을 골랐다. 같은 프레임에서 잰 크기는 0.82 → 34,431B / **0.88 → 43,132B** /
0.92 → 54,591B다. 화면의 대부분이 항성 둘레의 완만한 어두운 그라데이션이라 JPEG 아티팩트가
가장 잘 드러나는 종류의 그림이고, 43KB는 미리보기 자산으로 충분히 작다.
