# assets — 배포 자산

앱이 실행 중에 읽어 가는 정적 파일을 둔다. 여기 있는 파일은 **저장소에 커밋되고 배포에 실린다**
(`.gitignore`의 `*.png`/`*.jpg` 규칙에서 이 폴더만 예외로 열어 뒀다).

| 파일 | 쓰는 곳 | 크기 | 없으면 |
|---|---|---|---|
| `card-bg.jpg` | 관계 카드 배경 (`CARD_BG_SRC`) | 1080 × 1350 | 앱이 캔버스로 우주 배경을 직접 그린다 — 기능은 그대로 동작한다 |

`../og-image.jpg` (1200 × 630)는 공유 미리보기용이라 저장소 루트에 있다. `og:image` 메타 태그가
절대 주소로 가리키기 때문에 자리를 옮기면 그 태그도 함께 고쳐야 한다.

## 배경을 바꾸려면

`card-bg.jpg` **파일 하나만 바꿔 넣으면 된다.** 코드는 손대지 않는다 — 경로가
`index.html`의 `CARD_BG_SRC` 상수 한 곳에만 적혀 있고, 그림은 `cover` 방식으로
카드 크기에 맞춰 잘려 들어간다(비율이 달라도 늘어나지 않는다).

조건 두 가지:

- **글자·워터마크가 없을 것.** 카드 글은 앱이 그 위에 그린다. 그림에 글이 있으면 겹친다.
- **어두울 것.** 글자 깔개(위아래로 옅어지는 검정 그라디언트)를 얹지만, 밝은 그림 위에서는
  흰 글씨가 읽히지 않는다.

## candidates/ — 고르기 전의 후보들

[2026-08-30] 생성 도구(Magnific)로 카드용 3장·OG용 3장을 만들어 전부 남겨 뒀다.
**지금 적용된 한 쌍은 임시 선택이다** — 최종 선택은 후보를 눈으로 보고 정한다.

| 후보 | 규격 | 지금 |
|---|---|---|
| `candidates/card-a.jpg` | 1080 × 1350 | **→ `card-bg.jpg` 로 적용** |
| `candidates/card-b.jpg` | 1080 × 1350 | |
| `candidates/card-c.jpg` | 1080 × 1350 | |
| `candidates/og-a.jpg` | 1200 × 630 | 상하 레터박스 이음매가 있어 제외 |
| `candidates/og-b.jpg` | 1200 × 630 | |
| `candidates/og-c.jpg` | 1200 × 630 | **→ `../og-image.jpg` 로 적용** |

`*-src.png`는 **생성기가 내놓은 원본**이다(카드 896×1152, OG 1536×768). 요구 비율과 달라서
중앙 크롭 후 축소해 위 `.jpg`를 만들었다 — 원본을 남겨 두는 이유는 나중에 다른 비율
(예: 정사각 공유 이미지)이 필요할 때 다시 자를 수 있어야 하기 때문이다.

**바꾸는 법**: `cp assets/candidates/card-b.jpg assets/card-bg.jpg` — 코드는 손대지 않는다.

각 후보의 생성 프롬프트는 `candidates/PROMPTS.md`에 적어 뒀다 — 왜 그렇게 적었는지는 `HANDOFF-v2.md` §5.9.

## 톤 기준

카드 배경은 앱의 우주 배경(`#11121d` 계열)과 이질감이 없어야 한다. 고를 때 평균 RGB를 재
비교했다 — `card-a` `#10131d`(차 -1/+1/0), `card-b` `#1b2632`(차 +10/+20/+21),
`card-c` `#0a0c1b`(차 -7/-6/-2). `card-b`는 눈에 띄게 밝고 청록 쪽이라 깔개를 얹어도
서명 줄에서 가장 밝았다(합성 후 최대 휘도 98.8 / card-a 77.7 / card-c 24.2).
