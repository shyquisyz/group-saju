# 그룹사주 <sub>(가칭)</sub>

**여러 사람의 관계를 사주로 보는 웹 프로토타입.**
등록한 사람들을 그룹으로 묶으면 그 그룹이 하나의 **항성계**가 되어 화면에 뜨고,
관계 해석이 자동으로 만들어진다.

> 이름 **그룹사주는 가칭**이다. 바뀔 수 있다.

---

## 왜 만들었나

사주 앱은 많은데 전부 **개인 풀이** 아니면 **1:1 궁합**에서 멈춘다.
그런데 사람들이 실제로 궁금해하는 건 "내 사주"가 아니라 **"우리 사이가 왜 이런가"** 다.

- 우리 가족은 왜 이 조합에서 늘 부딪히나
- 이 팀은 왜 결정이 안 나나
- 저 사람이 빠지면 분위기가 왜 달라지나

여러 명을 한 판에 놓고 **관계의 구조**를 보는 도구가 없어서 만들었다.

---

## 어떻게 보이나

화면은 **은하**다. 은유가 하나씩 뜻을 갖는다.

| 화면의 것 | 뜻 |
|---|---|
| 한가운데 빛나는 **항성** | **나**. 원점에 고정된 건 이것 하나뿐이다 |
| 나를 **통과하는 궤도** | 그룹. 관계란 결국 나를 거쳐 간다 |
| 궤도를 도는 **행성** | 그 그룹의 사람들 |
| 행성이 항성 곁을 **지날 때 밝아짐** | 그 관계가 지금 가까워지는 국면 |

**행성의 생김새가 곧 그 사람의 일간(日干)이다.** 열 가지가 전부 다르게 생겼다 —
큰 나무(甲)는 유리구슬 안의 작은 숲, 태양(丙)은 흑점이 도는 불타는 표면,
촛불(丁)은 그을린 등피 안에서 흔들리는 불,
큰 산(戊)은 눈 덮인 봉우리가 선 알프스, 논밭(己)은 이랑이 난 경작지…

그룹을 고르면 **그 성계만 남고** 사람들이 나를 중심으로 돈다. 사람을 누르면 가까이 간다.

## 실행

빌드도 설치도 없다. **웹 브라우저만 있으면 된다.**

```bash
git clone https://github.com/shyquisyz/group-saju.git
cd group-saju
python -m http.server 8899
# → http://localhost:8899
```

`file://`로 직접 열어도 대체로 뜨지만 일부 기능이 막히므로 로컬 서버를 권한다.
인터넷 연결이 필요하다 — Three.js와 후처리 애드온을 CDN에서 받는다.
후처리를 못 받으면 **화면 번짐 효과만 자동으로 꺼지고** 나머지는 그대로 돈다.

### 처음 열면 자기 등록부터

**이 저장소에는 사람 데이터가 없다.** 그래서 처음 열면 **자기 등록 화면**이 먼저 뜬다 —
이름·생년월일·시각·도시·성별을 넣으면 그 사람이 은하의 유일한 항성("나")이 된다.
모든 관계가 "나"를 기준으로 계산되므로 **건너뛸 수 없다.**

내 사람들로 보려면 루트에 **`my-data.js`** 를 만들면 된다. 형식은 이렇다:

```js
window.SEED = {
  people: [
    {key:'me',  name:'나',   isMe:true,          // isMe는 정확히 한 명
      birth:{y:1990,m:1,d:1, sijin:12, city:'서울'}},
    {key:'a',   name:'친구',
      birth:{y:1990,m:1,d:1, sijin:12, city:'서울', sex:'남'}}
  ],
  links:  [ ['me','a'] ],                        // 관계선(선택)
  groups: [ {key:'g1', name:'첫 그룹', type:'친구', members:['me','a']} ]
};
```

- `sijin`은 시진 번호 0~12 (12 = 시간 모름). `city`는 앱의 도시 목록에 있는 이름.
- 일간은 **생년월일에서 계산**한다 — 따로 적지 않는다.
- `type`은 연인·부부·가족·친척·친구·동료·기타 중 하나. `parent`로 그룹 안에 그룹을 넣을 수 있다.

> ⚠ **생년월일·출생시각·출생지·성별은 `my-data.js`에만 두세요.**
> 이 파일은 `.gitignore`에 있어 저장소에 올라가지 않습니다.
> 한 번 커밋되면 기록에 남아 되돌릴 수 없습니다.

## 만든 방식

Three.js 위에 바닐라 JS. 빌드 없이 파일 하나로 돈다.

수치는 대부분 **재서 정했다.** 천체가 화면에서 몇 픽셀인지, 궤도가 몇 프레임이나 겹치는지,
번짐 효과가 이름표를 얼마나 뭉개는지를 측정하고 그 값을 근거로 골랐다.
왜 그 값인지는 코드 주석과 `HANDOFF-v2.md`에 남아 있다.
