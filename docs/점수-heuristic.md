# 점수 heuristic — 서비스 내부 지표 [2026-09-20 U40]

**본 점수는 전통 명리의 공식 수치가 아니라 여러 명리 신호의 상대적 활성도를 비교하기 위한 서비스 내부 heuristic이다.**
UI에는 수치를 보여 주지 않는다. 개발용 추적 함수(`traceLife`·`traceMonths`·`traceReasons`)로만 확인한다.

## 대운·운 기둥 활성도 (`luckForceTrace`)
| 신호 | 가중치 | reasonCode |
|---|---|---|
| 운 천간의 십성 갈래 | +1 | ACT_STEM |
| 운 지지 속 글자(지장간) | +1.5 × 날수 비율 | ACT_BRANCH |
| 원국과 새로 이루는 삼합·방합 | +1 (합의 오행 갈래) | ACT_COMBO |
| 원국과 새로 이루는 반합 | +0.5 | ACT_COMBO |
- wealth = 재성, career = (관성 + 식상) × 0.75.
- **activation은 "그 영역이 얼마나 움직이나"다. 좋은 운 점수가 아니다.** 일간 강약을 읽지 않는다(신강·신약으로 깎지 않는다).

## 관계(짝) 활성도 (`relationTrace`) — wealth와 다른 경로
| 신호 | 가중치 | reasonCode |
|---|---|---|
| 짝 별(남 재성·여 관성) — 천간 | +1 | SPOUSE_STAR_STEM |
| 짝 별 — 지지 속 글자 | +1 × 날수 비율 | SPOUSE_STAR_BRANCH |
| 배우자 자리(일지)와 충 | +1 | SPOUSE_PALACE_CHUNG |
| 배우자 자리와 육합 | +0.8 | SPOUSE_PALACE_YUKHAP |
| 배우자 자리와 형·자형 | +0.6 | SPOUSE_PALACE_HYEONG |
| 배우자 자리가 삼합·방합·반합에 묶임 | +0.6 | SPOUSE_PALACE_COMBO |
| 일간과 운 천간의 합 | +0.6 | DAYMASTER_GANHAP |
- 두 최종 숫자가 우연히 같아지는 것은 오류가 아니다. 검사는 별칭 여부와 reasonCode 구성으로 한다(자가진단 relationPath).

## 감당 (`themeCapacity`) — activation과 별개
- 일간 강약(월지 무게 3이 들어간 균형 지표 = 계절·전체 균형 반영)으로 그 테마를 얼마나 편하게 받는지를 정한다.
- 결과 코드: CAP_EASY / CAP_HEAVY / CAP_OVER / CAP_EVEN.
- 문장은 "활성 문장 → 감당 문장" 순서로 나눈다.

## 월운 세 지표 (`yearMonths`) — 서비스 설명용
| 지표 | 계산 |
|---|---|
| moneyActivity | 재성 활성 + 식상 활성 × 0.5 |
| recoveryLearning | 인성 활성 + 비겁 활성 × 0.5 |
| changePressure | 관계 발견 가중 합 — 충(일 1 · 월 0.8 · 년·시 0.6) · 형 0.5 · 육합·천간합 0.3 · 삼합·방합 0.5 · 반합 0.3 + 대운 지지와 충 0.6 + 세운 지지와 충 0.4 |
- 표시 문턱 = 무작위 600명 × 12달 표본의 75백분위(돈 1.15 · 회복 1.18 · 변화 1.5) → 각 표시가 약 24~26%.
- **합도 변화에 들어간다**(묶이고 다시 짜이는 것). 합 = 좋음, 충 = 나쁨으로 옮기지 않는다.

## 합·충·형 다섯 단계
1. 관계 발견 — `detectInteractions` (relation)
2. 닿은 원국 자리 — natalPos
3. 그 자리의 영역 — area (년 = 집안·오래된 관계 · 월 = 일·사회 환경 · 일 = 나·배우자 자리 · 시 = 자녀·계획·말년)
4. 다른 관계·계절·대운과 함께 본 테마 활성도 + 감당(따로)
5. 그 뒤에만 자연어 문장

## 자식(이 앱의 규칙 — 학파마다 다름)
- 남성: 관살(관성)을 자녀별 중 하나의 기준으로 쓴다. 여성: 식상을 자녀별 중 하나의 기준으로 쓴다.
- 시주·시지는 따로 자녀 자리(자녀궁)로 쓴다.
- 자식 관련 해 = 그해 자녀별이 들고 **동시에** 그해 지지가 시지와 합·충·형으로 닿을 때. 시각을 모르면 해를 짚지 않는다.
- 다른 체계(예: 여성 관성 = 자식 등)와 섞지 않는다.
