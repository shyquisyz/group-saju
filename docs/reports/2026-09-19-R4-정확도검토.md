# R4 — "사주가 잘 안 맞는 것 같다" 검토 [2026-09-19]

- 실행 모델: Opus 5 — 계산 대조·판정 분포 실측·원인 진단이라 적정.
- [비용 수준: 중 — 외부 대조, 무작위 4,000명 분포 두 번]

## 결론
**여덟 글자 계산은 맞다. 문제는 해석 — "기운의 세기" 판정이 '약하다' 쪽으로 크게 쏠려 있다.** 이 판정이 풀이 곳곳(올해 도움/부담, 관계 세기 문장,
일 꼬리, 돈 스타일, 힘이 되는 기운, 일하는 방식)에 쓰여서, 거의 모두가 "기운이 넉넉하지 않아요 · 도움을 받으세요" 쪽 말을 듣는다.

## 실측
1. **계산**: 등록 10명의 년·월·일주를 lunar-javascript 1.7.7과 대조 — **10/10 일치**(시각은 전원 모름이라 시주 없음)
2. **세기 판정 분포**(무작위 4,000명)
   | | 약한 편(극약+신약) | 센 편(신강+극왕) |
   |---|---|---|
   | 시각 모름 2,000명 | **78.8%** | 21.3% |
   | 시각 있음 2,000명 | **68.2%** | 31.9% |
   | 등록 10명 | 8명 | 2명 |
3. **원인**: 지금 판정은 득령(월지)·득지(일지 12운성)·득세(천간 2/3 이상) **세 조건 중 둘 이상**이면 신강. 조건마다 성립 확률이 3분의 1 안팎이라
   둘 이상 갖추기가 구조적으로 어렵다. 게다가 년지·시지 같은 **다른 지지는 아예 안 센다**
4. **점수제 시안**(앱 미적용, 브라우저에서만 계산): 일간 뺀 모든 글자를 자리별 가중치(월지 3 · 일지 1.5 · 나머지 1, 지지는 정기 십신)로 세어
   내 편(비겁·인성) 비율 → 중립점이 약 0.4(다섯 갈래 중 둘)라 **0.2 / 0.4 / 0.62**에서 가르면
   극약 18.9% · 신약 31.2% · 신강 27.6% · 극왕 22.4% — **약·강이 반반**
5. **등록 10명 중 4명이 바뀐다**: 신약→신강 1 · 신약→극왕 1(토 기운이 73%인데 지금은 신약 — 지금 판정이 틀린 경우) · 극약→신약 1 · 신강→극왕 2(더 강하게)

## 그 밖에 "덜 맞게" 만드는 것 (정도 순)
- **10명 모두 태어난 시각이 없다** — 여덟 글자 중 둘(시주)이 빠져 6글자로 본다. 시각 추정이라도 하면 나아진다
- 관계 풀이는 **두 사람의 태어난 날 윗글자(일간)만으로** 정한다 — 십신 하나로 문단이 정해져 거칠다
- 계절 보정(조후)을 안 본다 — 한겨울·한여름생은 판단이 달라질 수 있다
- 성별 빈 6명은 대운·연애·자식 풀이가 안 나온다

## 사용자 결정 필요 — 1건

   - 옛 방식(득령·득지·득세)은 근거 층에 "전통 세 조건"으로 계속 보여 준다 — 두 판정이 다르면 그 사실도 적는다
