# C7 — 여덟 코너 문구 전수 추출·진단 [2026-09-08]

읽기 전용 회차. 문구는 **한 줄도 고치지 않았다.** `index.html` 수정은 5단계(미사용 코드 정리)뿐이다.
커밋 없음.

측정 조건 — 배포본이 아니라 로컬 `http://127.0.0.1:8934/index.html`.
1900~2100년 생일을 하루 간격으로 **150,481건** 합성해 `personReading()`을 실제로 호출하고,
나온 문자열만 모았다(시각 있음 한 벌 + 시각 모름 한 벌). 손으로 문장을 재구성한 것은 없다.

## 0) 착수 실측에서 지시와 달랐던 것 — 먼저 읽을 것

1. **⑤~⑧ 네 코너의 문구에는 "임의 수정 금지" 표시가 붙어 있다.**
   `index.html` 3382행 주석: `[문안] 사용자가 준 것 그대로다. 임의 수정 금지.`
   이 주석은 「개인 해석 코너 넷」 블록 전체(JOB_LINE·MONEY_LINE·TIE_LINE·HELP_CLOSER)를 덮는다.
   → 4단계 개정안 중 ⑤⑥⑦⑧ 것은 **Teo 승인 없이는 반영하지 않는다.**
2. **⑧의 오행 뜻풀이(EL_TRAIT)는 그룹 패널과 공용이다.** 정의 8491행, 쓰는 곳 두 곳 —
   개인 코너 3445행, **그룹 「기운 분포」 8532행**. 고치면 그룹 패널 글자도 같이 바뀐다.
3. **`grep -n`이 이 파일을 이진으로 판정해 목록을 도중에 끊는다.** 그래서 5단계에서
   `wireHapChung` 호출을 "0곳"으로 잘못 세고 지웠다가 되돌렸다. **`grep -a`를 써야 한다.**
   (지난 C4 보고서의 참조 개수도 같은 방법으로 셌다 — 결론은 맞았지만 방법은 못 믿는다.)
4. 코너 개수는 지시대로 여덟이 맞다(분기표 C 해당 없음). 화면 제목과 코드 제목도 같다(분기표 A 해당 없음).
   위치를 못 찾은 코너 없음(분기표 B 해당 없음).

### ② 관심이 향하는 곳 — 조각 전량 + 대표 6

앞문장 10개 (실제 호출 결과 그대로. 틀은 `이 사람은 …에 마음이 갑니다(태어난 달의 기운 = 십신이름).`)

| 십신 | 마음이 가는 일 |
|---|---|
| 비견 | 나를 세우고 사람과 어울리는 일 |
| 겁재 | 겨루고 나누는 일 |
| 식신 | 꾸준히 만들어 내는 일 |
| 상관 | 드러내고 뒤집는 일 |
| 편재 | 크게 굴리고 넓히는 일 |
| 정재 | 차곡차곡 쌓는 일 |
| 편관 | 밀어붙이고 돌파하는 일 |
| 정관 | 규칙을 지키고 책임을 맡는 일 |
| 편인 | 남다른 방식으로 배우는 일 |
| 정인 | 배우고 돌보는 일 |

계열 이름 5개(`GROUP_POWER` — 이 표가 문장 전체의 어휘 기준이다):
스스로 버티는 기운(비겁) · 만들어 내고 표현하는 기운(식상) · 돈과 실속을 다루는 기운(재성) ·
규칙과 책임을 지는 기운(관성) · 배우고 받아들이는 기운(인성)

뒷문장 4문형:
1. 같은 갈래인 〈계열〉이 **넷~여덟**이나 되어, 판이 온통 그쪽으로 기울어 있습니다.
2. 같은 갈래인 〈계열〉이 셋이라 무대가 넓게 깔려 있습니다.
3. 같은 갈래인 〈계열〉이 둘이라 무게가 실려 있습니다.
4. 다만 같은 갈래가 하나뿐이라, 넓게 벌이기보다 한 곳을 깊게 파는 쪽입니다.

대표 6 = 위 앞문장(비견·정관·편재·정재·편인·상관)에 뒷문장 1~4를 붙인 것. 실제 최장은
`… 마음이 갑니다(태어난 달의 기운 = 정관). 같은 갈래인 규칙과 책임을 지는 기운이 다섯이나 되어, 판이 온통 그쪽으로 기울어 있습니다.`

### ③ 기운의 세기 (16 중, "출생 시각 모름" 꼬리를 뗀 8종 전량)

1. 태어난 달도, 태어난 날도, 겉에 드러난 글자들도 모두 이 사람을 받쳐 줍니다(극왕 — 셋을 다 갖춘 상태). 밀어붙이는 데 부족함이 없어, 오히려 **어디에 쓸지를 정하는 것**이 과제가 됩니다.
2. 태어난 달과 태어난 날이 이 사람을 받쳐 줍니다(신강 — 셋 중 둘을 갖춘 상태). 스스로 밀고 나갈 힘이 있습니다.
3. 태어난 달과 겉에 드러난 글자들이 … (신강, 결론 같음)
4. 태어난 날과 겉에 드러난 글자들이 … (신강, 결론 같음)
5. 태어난 달만 이 사람을 받쳐 줍니다(신약 — 셋 중 하나를 갖춘 상태). 혼자 지고 가기보다 **사람과 자리를 빌려 쓰는 쪽**이 잘 맞습니다.
6. 태어난 날만 … (신약, 결론 같음)
7. 겉에 드러난 글자들만 … (신약, 결론 같음)
8. 태어난 달도, 태어난 날도, 겉에 드러난 글자들도 이 사람을 받쳐 주지 않습니다(극약 — 하나도 못 갖춘 상태). 혼자 감당하기보다 **곁의 사람과 환경을 적극적으로 쓰는 편**이 맞습니다.

꼬리(시각 모름): 출생 시각을 모르는 상태의 판정이라 참고로 보십시오 — 시각을 넣으면 달라질 수 있습니다.

### ④ 넘치는 것과 비어 있는 것 — 문장 틀 5 + 대표 6

틀
1. 〈계열〉이 **N**으로 가장 많습니다. (동률이면 "…과 …이 N씩으로")
2. 반면 〈계열〉은 지금 아는 **여섯/여덟** 글자 안에 하나도 없습니다.
3. 아예 없는 사람이라는 뜻이 아니라 **타고난 무기가 아니라는 뜻**이라, 그쪽은 살면서 배워 채우는 영역이 됩니다.
4. 다섯 갈래가 고루 채워져 있어 한쪽으로 크게 쏠리지는 않습니다.
5. 겉으로 드러난 여덟 글자에는 〈오행〉 기운이 없지만, 글자 안에 숨은 기운(지장간)까지 세면 N이 들어 있습니다.

대표 6 (실제 출력)
1. 스스로 버티는 기운(비겁)이 셋으로 가장 많습니다. 다섯 갈래가 고루 채워져 있어 한쪽으로 크게 쏠리지는 않습니다.
2. 스스로 버티는 기운(비겁)과 배우고 받아들이는 기운(인성)이 둘씩으로 가장 많습니다. 다섯 갈래가 고루 채워져 있어 …
3. 스스로 버티는 기운(비겁)이 둘로 가장 많습니다. 반면 배우고 받아들이는 기운(인성)은 지금 아는 여섯 글자 안에 하나도 없습니다. 아예 없는 사람이라는 뜻이 아니라 … 겉으로 드러난 여섯 글자에는 화 기운이 없지만, 글자 안에 숨은 기운(지장간)까지 세면 둘이 들어 있습니다.
4. 배우고 받아들이는 기운(인성)이 둘로 가장 많습니다. 반면 스스로 버티는 기운(비겁)은 … 하나도 없습니다. …
5. 돈과 실속을 다루는 기운(재성)이 다섯으로 가장 많습니다. 반면 스스로 버티는 기운(비겁)과 배우고 받아들이는 기운(인성)은 지금 아는 여덟 글자 안에 하나도 없습니다. …
6. 규칙과 책임을 지는 기운(관성)이 여섯으로 가장 많습니다. 반면 스스로 버티는 기운(비겁), 만들어 내고 표현하는 기운(식상), 배우고 받아들이는 기운(인성) 셋은 지금 아는 여덟 글자 안에 하나도 없습니다. …

### ⑤ 어울리는 일 — 해석 6종 전량 (상수 그대로)

| 갈래 | 문구 |
|---|---|
| 식상 | 생각을 밖으로 꺼내는 일 — 만들고, 쓰고, 가르치고, 보여주는 일이 어울립니다. 다만 정해진 틀을 반복하는 자리에서는 답답해지기 쉽습니다. |
| 재성 | 벌이고 굴리는 일 — 사고팔고, 사람을 만나고, 판을 넓히는 일이 어울립니다. 다만 결과가 눈에 보이지 않는 일에서는 흥이 나지 않기 쉽습니다. |
| 관성 | 맡아서 지키는 일 — 책임지고, 관리하고, 질서를 세우는 일이 어울립니다. 다만 규칙 없이 굴러가는 판에서는 스트레스가 쌓이기 쉽습니다. |
| 인성 | 받아들이고 깊어지는 일 — 배우고, 파고들고, 다듬는 일이 어울립니다. 다만 빠른 결정을 재촉받는 자리에서는 힘이 빠지기 쉽습니다. |
| 비겁 | 제 힘으로 서는 일 — 스스로 결정하고 밀고 나가는 일이 어울립니다. 다만 시키는 대로만 해야 하는 자리에서는 오래 버티기 어렵습니다. |

### ⑧ 힘이 되는 기운 — 조각 전량

오행 뜻풀이(`EL_TRAIT` — **그룹 패널과 공용**):
목 — 뻗어 나가는 기운 / 화 — 타올라 드러내는 기운 / 토 — 받치고 아우르는 기운 /
금 — 거두어 벼리는 기운 / 수 — 스며들어 궁리하는 기운

해설 3문형:

## 사용자 결정 필요

1. **⑤~⑧ 문안을 손대도 되는가.** 코드에 "사용자가 준 것 그대로다. 임의 수정 금지"가 붙어 있어
   14건을 초안으로만 두었다. [권장] 겹침(ㄹ·ㅁ)만 고치고 뜻은 그대로 두는 선에서 승인.
2. **② 괄호 안 십신 이름을 뺄 것인가.** 빼면 용어가 사라지지만 "왜 그렇게 보는가"의 근거도 사라진다.
   [권장] 뺀다 — 같은 근거가 바로 위 사주 표에 글자로 이미 있다.
3. **③ 괄호 안 극왕/신강/신약/극약을 뺄 것인가.** [권장] 뺀다. "셋 중 몇을 갖췄는지"는 남으므로
   정보가 사라지지 않는다.
4. **⑧ 오행 뜻풀이는 그룹 패널과 공용이다.** 고치면 그룹 화면도 같이 바뀐다.
   [권장] 이번엔 건드리지 않는다(진단도 유지로 냈다).
