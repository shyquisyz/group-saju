# U39 — 근거 역추적 검증 [2026-09-20]

- 실행 모델: Opus 5 — 계산 경로 추적과 검증 도구를 만드는 회차라 적정.
- [비용 수준: 중 — 추적 함수 4개 + 나이 표기 7곳 + 피드백 경로 1곳 + 자가진단 2개]
- 사용자: "문장을 또 고치는 작업이 아니라, 현재 결과가 어떤 명리 계산에서 나왔는지 역추적하는 검증 회차". 금지 문자열은 건드리지 않았다.
- 테스트 인물: 구성원A(丙寅 辛丑 壬午 己酉, 남) — 메모리에서만 계산, 저장 안 함.

## 1. 나이 표기 통일 — 고침
- 원인:
  - 연도 옆 나이는 `Y − 출생 연도`("2027년(40살)")였다.
  - 대운은 `Math.round(시작 나이 40.67)` = "41~51살"로 올림했다.
  - "1년쯤 뒤(41살 무렵)"는 `Math.round(남은 해)`였다.
- 이제:
  - 연도 옆: **만 N세**(그해 생일이 지난 뒤). "2027년(만 40세)".
  - 대운: 생일 + 시작 나이(소수)로 **실제 날짜**를 구해 "2027년 후반~2037년 후반, 만 40~50세", 다음 대운은 "2027년 후반 무렵(만 40세)부터". 나이는 반올림 대신 내림이다.
  - 평생 흐름·궁금한 것·지나온 길·대운 줄·첫 대운 안내가 모두 같은 규칙(`daeunWhen`·`daeunSpanText`)이다.
- 실측: 화면 전체에서 나이 표기를 뽑으니 "살"이 0개다(부록 D).

## 2. 평생 흐름 최고점 근거 — 추적 함수 `traceLife(n)`
- 점수 구조: **십성 개수 세기가 아니다.** `luckForceTrace` = 천간 1 + 지지 1.5×지장간 날수 비율 + 원국과 새로 이루는 합(삼합·방합 +1, 반합 +.5).
  - wealth = 재성
  - career = (관성+식상)×0.75
  - relationship = 짝 별(남 재성 · 여 관성)
  - 0~3으로 자른다.
- **일간 감당력(신약)은 점수에 넣지 않았다** — 대운 문장("모자란 힘을 채워 주는 / 힘 조절이 필요해요")에만 반영한다. 점수에도 넣을지는 결정 필요(아래).
- 결과(부록 B):
  - 돈 최고 = 丙午 2.5(천간 丙 편재 +1 · 午 속 丙 +.5 · 丁 +.5 · 寅午 반합 +.5).
  - 일 최고 = 甲辰 1.76(辰 속 戊 편관 +.9 · 甲 식신 +1 · 乙 상관 +.45).
  - 관계 최고 = 丙午 2.5.
- **발견한 문제**: 남자는 relationship이 wealth와 **같은 재성**이라 두 곡선이 똑같다 — "관계에 마음이 가장 많이 가는 때"가 "돈 규모가 가장 커지는 때"와 항상 겹친다. 배우자 자리(일지)와의 합충을 보지 않는다.

## 3. 문장별 reasonCode — `traceReasons(n)` (부록 A, 37줄)
- 사용자가 짚은 여덟 문장:
  - 자리와 직함이 따라오는 사주 / 책임을 맡을수록 커져요 → `askHtml` · **WORK_GWAN_COUNT** · 관성 2개(월지 丑 본기 정관 · 시간 己 정관) → 개수 ≥2이면 고정 문장
  - 사람을 끄는 힘이 있어요 → `askHtml` · **LOVE_SPOUSE_STAR** · 짝 별(재성) 2개(년간 丙 편재 · 일지 午 본기 정재) + 결혼 → 고정 문장
  - 아이 일에 마음이 많이 가요 → `askHtml` · **KIDS_STAR_COUNT** · 관성 2개 — **일·명예와 같은 값**
  - 혼자보다 같이 굴릴 때 남아요 → `askHtml` · **MONEY_WEAK_MANY** · 신약 + 재성 2개
  - 편한 상대는 딱 부러지는 사람 → `cornerTie` · **TIE_MATE_EL** · 신약 → 나를 낳는 오행(금) → EL_PEOPLE.geum 고정 문장
  - 나이 들수록 자리가 잡혀요 → `personReading ⑤` · **PILLAR_POS_HOUR** · 시간 己 = 정관 → 자리별 원고
  - 가까운 사람 살림을 제 것처럼 챙겨요 → `personReading ⑤` · **PILLAR_POS_DAY** · 일지 午 본기 = 정재 → 자리별 원고
- **일주별 고정 카피**: DAYMASTER_COPY(STEM_BLURB — "하나를 물으면…"), TIE_DAYMASTER_COPY(TIE_STEM — "상대 마음을 조용히…") — 일간 하나로 정해진다. ("dayPillarPersonality"가 아니라 **일간(dayMaster) 고정**이다 — 일지는 안 본다)
- 추적 방식: 문장을 다시 쓰지 않고 **같은 표·같은 입력**으로 코드를 다시 뽑고, 화면에서 찾을 조각(probe)을 기록한다. 자가진단 **traceVerify**가 probe가 실제 패널 글에 있는지 확인한다(37/37 있음) — 추적과 출력이 갈라지면 걸린다.
- 한계: 추적 대상은 핵심 37개다. 화면의 모든 문장(예: 관계 렌즈·그룹 보고서)에 reasonCode가 달린 것은 아니다.

## 4. 지나온 길 답 — 계산층 분리 확인·고침
- 코드 확인(`n.past` 읽는 곳 전수):
  - `pastSummary`(요약 문장)
  - `pastHtml`(버튼 표시)
  - `jobFitLine`(직업 한 줄)
  - 그룹 `sharedHtml`(버튼·요약)
  - → 모두 표시층이다. `pastYears`·`hourProbes`·`gangyak`·`luckForce`·`sajuOf`는 답을 읽지 않는다.
- **위반 1곳 발견·삭제**: 「이 시각으로 추정해 두기」 버튼이 답으로 고른 시진을 `birth.est`에 바로 써서 **여덟 글자(시주)를 바꿨다.** 버튼을 지우고 "시각 추정에서 확인하기"(별도 질문 흐름)로만 보낸다.
- 자가진단 **feedbackInvariant**: 가상 인물에 답·직업을 넣기 전후로 여덟 글자·균형 지표·고른 해·시각 질문 해·대운 점수 서명이 같다(통과).

## 5. 「오늘」 생성 경로
- `todayHtml`:
  - 오늘 **일진을 실제 날짜로 계산**한다(`luckNow().day` = sajuOf(오늘 KST)). 오늘 丁酉.
  - 천간 십성 갈래 → DAY_LINE(갈래별 고정 두 문장 — "장바구니는 한 번 더 보고 결제하세요"는 고정 조언).
  - 일지와 합충 → DAY_HIT.
  - 지지 본기 십성 갈래 → DAY_LUCK.
- **대운·세운은 결합하지 않는다.** 랜덤·요일·해시는 아니다(같은 날·같은 사람 = 같은 문장).
- 「오늘의 작은 행운」 → **「오늘의 작은 제안」**으로 바꿨다(갈래별 고정 제안 = 엔터테인먼트임을 이름으로 구분).

## 6. 「이번 달」·12달 검증 — `traceMonths(n)` (부록 C)
- 월주는 **절입 기준**이다 — 입춘 2026-02-04 · 경칩 03-05 · … · 백로 09-07 · 한로 10-08(절기 표 solar-terms.js). "이번 달"은 백로~한로의 丁酉월.
- 판정 규칙(yearMonths):
  - 조심할 달 = 일지 충(12월 庚子 — 子午).
  - 좋은 달 = 일지와 합(7월 乙未 午未 육합 · 9월 丁酉 丁壬 합) 또는 천간·지지 둘 다 억부 도움.
- **판정에 안 쓰는 것**: 월지·시지·년지의 충(예: 7월은 월지 丑未 충이 있는데 "좋은 달"), 형, 대운·세운과 월주의 관계(8월 대운 육합 · 11월 대운 巳亥 충 · 12월 세운 子午 충은 계산만 되고 판정에 안 들어감).
- 제안([권장], 이번엔 안 고침): "좋은 달/조심할 달" 대신 영역별 세 표시 — 돈·활동이 강한 달(재성·식상) / 회복·배움이 편한 달(인성·비겁 + 억부 도움) / 변화가 큰 달(원국·대운·세운과 충형).

## 7. 근거가 약하거나 없는 문장(별도 목록 — 이번엔 고치지 않음)
1. **관계 곡선 = 돈 곡선(남자)** — "관계에 마음이 가장 많이 가는 때"에 독립 근거가 없다.
2. **"아이 일에 마음이 많이 가요"** — 「일·명예」와 같은 관성 개수를 쓴다(자녀 자리 = 시주는 안 봄).
3. **"사람을 끄는 힘이 있어요"** — 재성 2개 → "끄는 힘"은 해석 비약(재성은 돈·현실 욕구도 뜻한다).
4. **"편한 상대는 딱 부러지는 사람"** — 억부(신약 → 금)만으로 정한 오행을 성격 유형으로 바꿨다(조후·월령 미반영).
5. **「좋은 달」 7월** — 월지 丑未 충을 판정에서 뺀 채 "좋은 달".
6. **"어깨가 무거울 거예요"(올해)** — 억부 도움 여부만으로 감정 상태를 단정.
7. **DAY_LINE 조언 꼬리**("장바구니는 한 번 더 보고 결제하세요") — 갈래별 고정 조언.
8. **"오늘의 작은 제안"** — 엔터테인먼트(이름으로 구분 완료).
9. **자리별 원고의 꾸밈**("냉장고 사정까지 알아요") — 근거(일지 정재)는 있으나 묘사는 고정 카피.

## 사용자 결정 필요 — 3건
1. **관계(짝) 곡선**: 남자 재성 = 돈과 같은 값이라 곡선이 겹친다. 일지(배우자 자리)와 대운 지지의 합충을 더해 독립시키기 [권장] / 그대로.
2. **12달 표시**: 좋은 달/조심할 달 → 영역별 세 표시(돈·활동 / 회복·배움 / 변화)로 바꾸고, 원국 전 자리·대운·세운 충을 "변화가 큰 달"에 넣기 [권장] / 그대로.
3. **감당력 보정**: 대운 점수에 신약·신강 보정을 넣기 / 지금처럼 문장에만 [권장 — 점수는 "규모", 감당은 문장으로 나누는 게 읽기 쉽다].
