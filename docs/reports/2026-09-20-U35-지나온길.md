# U35 — 지나온 길 + 답으로 보정 [2026-09-20]

- 실행 모델: Opus 5 — 저장 형식 변경 + 계산·문장·흐름 설계 회차라 적정. 다음(그룹 「같이 겪은 해」)도 [권장] 같은 급.
- [비용 수준: 중 — 저장 v9 + 함수 10여 개 + 폰 크기 실제 흐름 두 가지]
- 사용자: "과거의 이력도 사주로 표기해야", "맞는지 받을 거면 선택으로 사주가 더 정교해지는 게 있어야", "권장대로 지나온 길 진행하자"

## 무엇
- 인물 패널 「지나온 길」. 나는 평생 흐름 뒤, 다른 사람은 「나와의 관계」 뒤(그 사람 화면은 관계가 먼저).
- **해 고르기**: 12살 이후 지난해까지 중 변화 압력이 큰 해.
  - 점수: 충(일 3 · 월 2.5 · 년 1.5 · 시 1.5) · 일지 합 1.5 · 형 .8 · 대운이 **실제로 바뀐 날짜**의 해 1.2. 합이 2.5 이상인 해만 후보.
  - 2년 이상 떨어진 해만 최대 일곱 개.
  - 문장은 U32 기준(변화 압력 + 괄호 안 예시)에 "그해 기운은 ○○ 쪽".
- 해마다 「맞아요 · 아니에요 · 기억 안 나요」.
- **답의 쓰임**
  1. **적중**: "답한 해 4개 중 3개가 맞았어요" + 넷 이상 답하면 판정.
     - 70% 이상: 잘 맞는 편
     - 40% 이상: 시각 확인 권유
     - 그 미만: 날짜·시각·출생지·음력 여부를 다시 확인하라는 안내
  2. **시각 좁히기**: 시각을 모르면 "그 시진에서만 부딪히는 해" 셋을 더 묻는다(최근 해부터, 시진이 겹치지 않게). '맞아요'가 딱 하나면 그 시진을 **가능성으로** 권하고 「이 시각으로 추정해 두기」(birth.est) · 「질문으로 더 좁히기」(기존 시각 추정)를 보여 준다.
  3. **직업**: "지금 하는 일은 어느 쪽에 가까워요?" 여섯 칩. 고르면 「어울리는 일」 끝에 한 줄이 붙는다 — 사주의 격·짜임·가장 센 세력과 닿으면 "맞닿아 있어요", 아니면 "결이 조금 달라요 — 일 안에서 ○○을 맡으면 덜 소모돼요".
- **저장 v9**: 사람마다 `past = {answers:{연도:y|n|?}, job, at}`. `MIGRATIONS['8']`이 past:null을 넣고, pastClean이 잘못된 값을 버린다.

## 실측 (폰 375×812, 저장 끈 채 메모리에서)
- 기준 인물(성별·시각 넣음):
  - 고른 해: 2003(4.0) · 2008(3.0) · 2015(4.0) · 2017(3.5, 대운 전환) · 2020(3.0).
  - 처음엔 대운 전환 해를 "생년+나이 반올림"으로 셌다가 2018로 밀렸다 → 실제 날짜로 고쳤다. 3년 간격이면 2017이 2015에 밀려 빠졌다 → 2년으로 바꿨다.
- 답 4개(맞아요 3 · 아니에요 1) → "답한 해 4개 중 3개가 맞았어요. 사주의 흐름이 지난 삶과 잘 맞는 편이에요". 직업 「기획·사업」 → "사주의 돈과 결과를 챙기는 기운과 맞닿아 있어요".
- 시각 모르는 사람: 시각 질문 2023·2024·2025. 아니에요·맞아요 → "술시(19-21시)일 가능성" → 추정해 두기 → 시주 丙戌, 계산 모드 est.
- 부팅: 로컬 v8 저장본이 v9로 열림(loadFailed null, 10명·7그룹). 자가진단 **121/121**(past 추가, 금지어 검사에 지나온 길 포함).

## 한계
- 시각 질문은 세 시진만 가린다(12개 중 3개). 셋 다 '아니에요'면 권유가 없고 「질문으로 더 좁히기」로 넘긴다.
- 시각을 이미 아는 사람에게 "시각 확인용 해"(시지만 부딪히는 해)는 따로 묻지 않는다 — 시지 충 단독(1.5)은 후보 문턱(2.5)에 못 미친다.
- 재성 해의 좋고 나쁨으로 세기를 보정하는 것은 이번에 넣지 않았다 — 답이 쌓인 뒤 규칙을 정하는 게 맞다 [권장].
