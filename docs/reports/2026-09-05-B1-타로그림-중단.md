## 3. 사용자 결정 필요

**1건 — Magnific MCP를 새 경로에 등록한다.** 등록은 설정 파일을 바꾸는 일이고 로그인(OAuth)이 붙을 수
있어 사용자가 직접 해야 한다. 세션이 시작될 때 읽는 값이라 **등록 뒤 Claude Code를 다시 시작**해야 한다.

1. 이 폴더에서 터미널을 열고 아래를 실행한다(프롬프트에 `!`를 붙이면 이 세션 안에서도 돌릴 수 있다):
   ```
   claude mcp add --transport http magnific https://mcp.magnific.com
   ```
2. 로그인 창이 뜨면 Magnific 계정으로 승인한다.
3. Claude Code를 다시 시작한 뒤 `/mcp`로 `magnific`이 연결됐는지 본다.
4. 그다음 B 1/2 지시문을 **그대로 다시** 준다 — 프롬프트·파일명·합격 기준은 바꿀 것이 없다.

선택지: (가) 위대로 새 경로에 등록 [권장] (나) 옛 경로 항목을 지우고 전역(`--scope user`)으로 등록 —
세 프로젝트가 같은 서버를 쓰므로 한 번에 정리된다. 다만 전역 등록은 이 앱과 무관한 폴더에서도
Magnific이 뜬다.
