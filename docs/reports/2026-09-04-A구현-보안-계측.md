## 1. 한 것 (커밋 순)

정리(3): 건강 확인값 groups 4→3 정정 · 로컬 서버 규칙 확정 · 상비 규칙 (9)~(13) 추가.

패널 개편(4):
1. `refactor(패널)` 패널 높이를 CSS 변수 `--panel-h`로 — 실측값(getBoundingClientRect)이라 tall·확대·짧은 패널에서 안 어긋난다.
2. `feat(패널)` 확대·닫기 버튼을 **패널 오른쪽 위, 제목 줄 높이에 붙박이**(사용자 결정). 확대 모드 추가. 기호는 폰 글꼴에 의존하지 않는 **인라인 SVG**.
3. `fix(패널)` 제목이 본문과 함께 스크롤(R1). 안쪽 ✕ 제거. 손잡이 40→28px.
4. `feat(태그바)` 패널이 열리면 태그바가 패널 위로(T1). 확대 모드에서는 숨김. 예시 모드의 「등록 화면 펼치기」 알약도 같이 올림.

보안·안정성(4):
5. `fix(보안)` 이름·그룹명·출생지·백업 값이 HTML로 해석되지 않게 출력 자리 34곳 이스케이프. 붙여넣기 불러오기의 오류 문구까지.
6. `fix(안정성)` three.js CDN 실패 → 안내 화면 + 다시 시도. WebGL 불가 → 안내 화면 + 다시 시도.
7. `fix(안정성)` 절기 표 실패 → 알림 + 새로고침 버튼.
8. `feat(계측)` 깔때기 사건 6개(`first-visit` `me-registered` `first-other-added` `card-created` `share-done` `image-saved`). 스위치 `ANALYTICS.ON=false`.

문서(2): HANDOFF §5-0 로드맵 갱신 · 설계안에 구현 완료 표시 · 이 보고.

## 3. 실측 결과 — 보안·안정성

- **이스케이프**: 이름 `<i id=…>`·`<u id=…>`, 출생지 `<b id=…>`, 그룹명 `<s id=…>`가 든 백업 텍스트를 붙여넣기 경로
  (`parseBackup` → `applyBackupSeed`)로 적재한 뒤 인물 패널·그룹 패널·관계 패널·관계 선택 시트·일괄 입력 시트·
  수정 시트를 열어 그 id의 요소를 찾음 → **전부 0개**. 고치기 전에는 인물 패널 해설 문장에서 2개 검출(조사 함수
  `josa`가 이름을 그대로 붙이고 있었다). 오류 문구(생일 99일)도 이스케이프돼 표시. 태그바·제목은 `<s id=…>`가
  글자 그대로 보인다.
- **CDN 실패**(three.min.js 404로 흉내): 고치기 전 검은 화면·첫 화면 없음. 지금은 「화면을 그리는 도구를 내려받지
  못했습니다」 + 다시 시도.
- **WebGL 불가**(getContext → null로 흉내): 「이 기기에서는 3D 화면을 그릴 수 없습니다」 + 다시 시도.
- **절기 표 실패**(404로 흉내): 사주 표 길이 0·개인 해석 null로 **비어 보였고**, 일간은 옛 계산으로 물러나 예시 8인
  모두 정상 로드와 같은 값(2,6,5,1,1,8,4,7). 틀린 계산은 아니라 계산을 끊지 않고 알림을 띄운다.

## 7. 그냥 진행함

- **확대 상태에서 아래로 끌면 52vh로 복귀**(설계안 §6-1의 (가)). 화면 전체에서 110px 규칙을 두면 읽다가 닫는 사고가 는다. 닫기는 ✕.
- **확대 상태를 기억하지 않는다**(§6-2). 닫으면 풀리고 다음 사람은 52vh. 기억하는 쪽은 나중에 `saveUiPref`에 얹을 수 있고, 안 기억하는 쪽이 되돌리기 쉽다.
- **tall(82vh)에서도 T1 그대로** — 태그바가 y 100~152에 앉는다(§6-5). 예외를 두지 않는 편이 규칙이 하나라 골랐다. 실기기에서 어색하면 tall에서 끄는 예외 한 줄이면 된다.
- **확대 버튼 기호는 텍스트 병기 대신 인라인 SVG** [권장 확정] — 글꼴 의존이 없어 "안 그려지는 폰" 문제가 사라진다. 텍스트 병기는 320에서 제목 자리를 더 먹는다.
- **절기 표 실패는 알림만, 계산 중단 안 함** — 일간 폴백이 정상 값과 같았고(위 §3), 새로고침으로 풀리는 일이다. 23~01시 정확 입력에서만 진태양시 보정과 갈릴 수 있다는 코드 주석의 실측이 있어, 그 경우는 알림이 대신한다.
- **`main` 직접 배포** — 상비 규칙 (13) 뿌리기 전 조건(자가진단 통과)을 따랐다.
- **버튼 층(z-index) 6** — 시안의 9 대신. 시트(8·13)·어둠막(7)보다 아래여야 시트가 뜰 때 버튼이 뚫고 나오지 않는다.
- **패널 개편 갈무리를 `docs/reports/…/`에 두고 `.gitignore` 예외 추가** — 설계안 갈무리와 같은 성격(우리 화면·예시 인물).
