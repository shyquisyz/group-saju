## 1. 입력값 → 화면 삽입 점검

**방법** — 정적 검색은 이름이 도우미 함수(`fillPair`·`josa`·`subjKo` 등)를 거쳐 들어가 빠짐없이 잡기
어렵다. 그래서 **실제로 넣고 열어 봤다.**

넣은 값(백업 파일 → `bkTryLoad` → "지우고 불러오기", 실제 사용자 경로):
- 이름: `나<img src=x onerror=…>` · `<img src=x onerror=…>` · `"><svg onload=…>` · `'-X('p4')-'`
- 그룹명: `<img src=x onerror=…>` · `<b onmouseover=…>그</b>` (하위 그룹)
- 도시명(자유 입력 칸): `<img src=x onerror=…>`
- `self`(A8)·시각 있는 사람·없는 사람을 섞었다

연 화면(각각 뒤에 실행 흔적·주입 요소 개수 측정):
불러오기 미리보기 · 인물 패널 4 · 그룹 패널 2 · 은하 전체 · 관계 패널 4(나↔3, 남↔남 1) · 관계선 4 ·
관계 보기 · 관계 선택 시트 · 가상 성계 담기·보기 · 사람 수정 시트 · 그룹 수정 시트 · 여러 명 추가 ·
설정 · 백업 · 카드 시트 · 스스로 본 모습 시트 · 시각 추정 · 시각 검증

```
모든 단계: 실행 0 · <img src=x> 0 · <svg onload> 0 · [onmouseover] 0
공격 문자열이 "글자로" 보인 칸: 18곳
```

**판정**: 지금 코드에서는 입력값이 실행되는 자리를 찾지 못했다. 다만 이건 **이번에 연 화면에 대한
결과**다 — B1 이후 새 화면(로그인·연결 목록·초대)을 만들 때 같은 시험을 반복한다 [권장].
시험 절차를 위에 그대로 적어 두었다.

## 2. 외부 파일 무결성(SRI)

| 파일 | 호스트 |
|---|---|
| three.min.js r128 | cdnjs |
| CopyShader · LuminosityHighPassShader · EffectComposer · RenderPass · ShaderPass · UnrealBloomPass (0.128.0) | jsDelivr |
| pretendard 1.3.9 CSS | cdnjs |

- 해시는 sha384. **같은 파일을 두 번 받아 해시가 같은 것을 확인**했다.
- 두 호스트 모두 `Access-Control-Allow-Origin: *`을 보낸다(확인) → `crossorigin="anonymous"`로 붙였다.
- **Google Fonts CSS에는 못 붙인다** — 접속한 브라우저에 따라 내용이 달라져 해시가 고정되지 않는다.
  폰트 CSS라 코드를 실행하지 않으므로 위험이 작다.
- **주의**: 라이브러리 버전을 올리면 해시도 다시 계산해야 한다. 안 그러면 파일이 막혀 3D가 안 뜬다.
  계산 명령은 `index.html` 주석에 적었다.
