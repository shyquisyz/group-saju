- 실행 모델: Opus 5 — 그림 판정·분류 규칙 진단이 있어 적정. 다음 회차(앱 적용)도 Opus 5 [권장].

## 경위 (사용자 피드백 순서)
1. "금이 하얀색이라 눈 같다" → 금속 후보 4종(건메탈·무지개 티타늄·보라 크롬·육각 판) → 크롬 지구 레퍼런스 →
   **거울 크롬**(금 영역만 반사를 켬, 스튜디오 조명 반사) 시안.
2. "눈과 금이 구분돼야" → 실측: 극 얼음은 파란 흰색(평균 RGB 193/219/245), 크롬은 중립 회색(129/129/127).
3. "금 + 겨울 수는?" → 바다가 어는 얼음층 시안. 사용자 "맞는지 모르겠다" → **실제 크기(132/68/20px) 시안**으로 비교.
4. 사용자 판정: 자연스러운 건 기존(A)인데 금 압도가 설산 같다 · 크롬(B)은 확실히 쇠 같지만 어색 · 얼음(C)은 경계가 어색.
   그리고 **"차가운 게 있으면 뜨거운 금속·물·목·토도 있어야 하지 않나"** → 온도(조후)는 오행과 별개의 축이라는 정리.
5. 온도 효과(대기·테두리·입자) 시안 + A에 약한 금속 반사(절충안) 시안 → 절충안은 흰 느낌이 안 빠져 **불합격**(자기 판정).
6. 금 색 자체를 바꾼 후보 G1 건메탈 암석 / G2 청회색 적철광 / **G3 백랍·백금 원석** → 사용자 **G3 채택**.

## 이번에 바꾼 것
- 금이 들어간 지도 **27장 교체**(G3 문구, "흰색·눈·얼음 절대 금지" 추가). 시험 때 만든 금 압도·금+토·수 2장은 그대로 채택, 25장 신규.
  세 오행 지도는 "보조 둘을 붙여서"로 생성. 금+화·수 / 금+수는 "금 70~75% 이상"으로 강화.
- 방향 측정 실패 3장(목+화·토, 목+토·금, 금+목·토)을 "보조를 작게, 같은 쪽에, 주 지형 띠로 떨어지게"로 재생성(후보 6장 중 3장 채택).
- **금 판정 규칙 변경**(`tools/planet-maps/facing.py`): 채도 <0.3 · 밝기 ≥55 · 주황기 없음. **금이 들어간 지도에서만** 적용 —
  화의 회색빛 지각이 금으로 잡히지 않게. 이전 규칙(채도<0.18·밝기≥110)은 새 금을 4~6%로만 잡았다 → 9~18%로 정상화.

## 온도 효과 — 시안만, 앱 미적용
- 규칙: 지도는 그대로, **행성 전체에 효과**를 얹는다(다섯 오행 모두 같은 규칙).
  차가움 = 옅은 푸른 서리 기운 + 가장자리 흰 테 + 눈송이 / 뜨거움 = 주황 기운 + 달아오른 테 + 떠오르는 불티.
- 처음엔 굵은 고리처럼 보여 어색 → 바깥으로 갈수록 사라지는 대기로 수정.
- 132·68px에서 구분됨, 20px에서는 색감 차이만.
- 코드 원형: `tools/planet-maps/temp-fx.js`(앱이 읽지 않음).
