# 2026-09-18 U4 — 오행 조합별 행성 지도 55장 생성

- 실행 모델: Opus 5 — 그림 판정·방향 측정 오류 진단이 있어 적정. 다음 회차(앱 적용) Opus 5 [권장].
- [비용 수준: 중 — 이미지 생성 65장(약 975 크레딧), 브라우저 렌더 측정 6회. 앱 코드 변경 없음]
- 사용자 요청: "만들어보자" (U3의 권장안 = 조합 53 + 압도 5 − 겹침 3 = 55장)

## 결과
- 원본 지도: `img/2026-09-17-U2/12-행성지도55-원본.jpg`
- 구에 입힌 모습: `img/2026-09-17-U2/11-행성지도55-구체.jpg` (각 행성은 아래 "보이는 방향"으로 돌린 것)
- 파일: `assets/planet-tex/map/{주}-{보조…}.jpg` 55장, 1024×512, 합계 7.7MB(장당 82~188KB)
  - 이름 규칙: 주 오행 먼저, 보조는 목·화·토·금·수 순. 예: `to-mok-hwa.jpg` = 토 주 + 목·화. 압도는 `geum.jpg`처럼 한 단어.
  - 한 오행만 있는 사람(토·수·화)도 압도 지도를 쓴다.
- 방향표: `assets/planet-tex/map/facing.json` — 지도마다 `yaw`(좌우 회전)·`pitch`(앞뒤 기울기)와 그때 보이는 오행 비율(%).
- **앱은 아직 이 파일들을 읽지 않는다**(적용은 다음 회차).
- Magnific 프로젝트 「사주은하 행성지도」에 원본이 모여 있다.

## 만든 방법
1. 지시문 틀 하나로 55장 생성(`tools/planet-maps/prompts.py`). 세 오행 = "주 65% + 보조 둘 각 15~20%", 두 오행 = "75% + 25%", 압도 = "온통 한 오행".
2. 시험 5장 → 두 가지 고침: 없는 오행이 섞여 들어옴(수·화·금 지도에 숲 섬) → **없는 오행은 "넣지 마" 문구 추가**. 금이 눈 덮인 산처럼 보임 → "크롬 금속, 눈 아님"으로 문구 강화.
3. 금 압도는 어둡고 칙칙해서 2장 더 생성 → 각진 면이 가장 뚜렷한 밝은 것 채택.
4. 이음새 제거: 좌우 끝 48px를 서로 섞음 → 좌우 차이 최대 26.7 → 0.3(그림 안쪽 인접 차이 최소 1.3보다 작음).

## 초상에서 어느 쪽을 보여 줄까 — 측정으로 정함
- 문제: 구는 한쪽 면만 보인다. 아무 방향으로 두면 "목 주"인데 사막만 보이는 일이 생긴다(첫 렌더에서 실제로 발생).
- 1차 — 지도 좌표로 보이는 면을 계산: 예측과 실제 렌더가 **21곳에서 어긋남**(회전 방향 환산 오류로 추정, 원인은 확정 못 함) → 폐기.
- 2차 — **실제로 돌려서 센다**: 지도를 오행별 단색 지도로 바꿔(`prep.py`), 브라우저에서 좌우 36방향 × 기울기 5단계로 렌더하고 픽셀을 셈(`check.html`의 `pickYaw`).
  기준: ① 주 오행이 가장 넓게 보일 것 ② 보조 오행이 모두 3% 이상 보일 것.
- 55장 중 기준 실패 4장 → 원인은 지도(보조 둘이 행성 반대편 / 금보다 바다가 큼) → 4장을 "보조끼리 붙여서", "금이 70% 이상"으로 다시 생성(8장 중 4장 채택).
- 붙여 놓으니 이번엔 둘이 함께 보이는 방향에서 보조가 주보다 커짐 → 기울기(위·아래에서 보기)도 함께 찾게 바꿈.
- **최종: 55장 중 54장 통과.** 남은 1장 `mok-hwa-to`는 화가 1%만 보임(목 67 · 토 27).
- 측정 조건: 렌더 96×96, 시야각 30°, 카메라 높이 0.3, 기울기 −0.45~0.45 5단계, 좌우 10° 간격.
- 측정 중 함정: 같은 주소의 그림을 브라우저가 캐시에서 읽어 교체 전 지도로 잰 적이 있음 → 주소에 시각 값을 붙여 해결.

## 남은 약점 (자기 판정)
- **극지방 왜곡**: 기울기를 ±0.9까지 허용하면 55장 모두 통과하지만, 극의 소용돌이 무늬가 보여서 ±0.45로 줄였다. 그래도 금+화 · 금 압도 · 화+토·금에서 약하게 보인다.
  → 고칠 방법 [권장]: 지도 위아래 끝을 흐리게 섞거나, 초상 렌더에서 극 쪽에 대기/구름을 얹기.
- `mok-hwa-to` 1장은 화가 거의 안 보임 → 한 번 더 생성하거나, 기울기 범위를 이 지도만 넓힌다.
- 오행 비율은 지시문 기준 "대략"이다(보이는 면 기준 주 오행 29~100%).
- 보조 둘의 크기 순서는 구분하지 않았다(U3에서 정한 53가지 기준).

## 사용자 결정 필요 — 2건
1. **앱 적용 범위**: 초상(홈·인물 패널)부터 [권장] / 은하 화면 행성까지 한 번에. 은하 화면에서는 행성이 3~20px라 차이가 작고, 55장을 모두 불러오면 7.7MB다.
2. **동점 규칙**(U3에서 이월): 일간 우선 [권장] / 목화토금수 순.
