# C6 — b·c줄 개정안 5건 치환 [2026-09-08]

## 착수 실측
- `REL_DESC`(3278행) 10개 항목 전부 `{b, c}` 구조 그대로. 파싱해 10개 확인.
- 치환 대상 5개 문자열 — 파일 전체에서 **각각 정확히 1번씩** 매치(분기표 A·B 해당 없음).

## 자가검증

**1) 40가지 재생성** — 십신 10 × (합충 없음·충·간합·육합) = 40개 전부 생성, 빈 문자열·`undefined` **0건**.
전문은 아래 「40가지 덤프」.

**2) 문장 길이** — 마침표 단위로 쪼개 잰 결과 **45자 초과 0건**, 최장 **38자**, 평균 **24.3자**.

**3) c줄 "대신" 시작** — **10/10 통과**

**4) 중복 재검사**
- (가) a줄 조각 낱말이 같은 십신의 b·c줄에 2개 이상 겹치는 행: **0건**.
  (C5에서 걸렸던 상관·정재·편인 세 건이 이번 치환으로 사라졌다.)
- (나) 서로 다른 십신끼리 같은 줄에서 낱말이 2개 이상 겹치는 쌍 — "대신"(c줄 공통 리듬, 의도된 것)을
  빼고 세면 **2쌍**뿐이다.
  - `b` 겁재↔식신 : 같이, 옆에, 있으면
  - `c` 정관↔정인 : 말해, 두세요
  낱말 1개만 겹치는 쌍은 27개인데 대부분 기능어("있으면", "사람이", "두세요", "먼저")다.

**5) 문법·콘솔** — 자가진단 **58/58 통과**. 새 페이지 로드(v=c6, v=c6b)에서 앱 코드 오류 **0건**.
콘솔에 남아 있는 예외 3건은 **직전 로드(v=c4) 시각의 것이고 내용이 브라우저 확장 메시지 채널 오류**
("A listener indicated an asynchronous response…")라 이 파일과 무관하다.
