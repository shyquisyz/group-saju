## 1. 무엇을 만드나

### ⓐ 시각 검증 — "알고 계신 시각이 맞는지 봐 드릴까요?"
- **대상**: 시각을 정확히 입력한 사람(`hasTime`). 사주 표 아래 버튼 한 줄.
- **흐름**: A5 시트(`estsheet`)를 `mode:'verify'`로 그대로 연다. 질문 엔진·가점·종료 조건 전부 같다.
- **결과**: 답으로 좁힌 칸과 입력된 시각의 칸(`hourToSijin` + 자시면 23/0 구분)을 비교해 §3-D 문장.
- **저장 안 함.** 검증은 한 번 보고 끝나는 기능이다 — `birth.est`를 덮어쓰면 안 된다(시각을 아는
  사람에게 추정값이 생기면 A5 안내와 섞인다).

### ⓑ 성향 테스트 — "스스로 본 모습"
- **대상**: 모든 사람. "나"는 "나를 더 알아보기", 다른 사람은 "이 사람을 떠올리며 답하기".
- **문항**: 10개. **다섯 계열을 두 개씩 짝지은 10쌍을 한 번씩** 묻는다(각 계열이 정확히 4번 나온다 —
  편향 없음). 보기 둘 + "둘 다 아니에요"(점수 없음).
- **점수**: 고른 보기의 계열에 +1. 계열별 0~4점. **최고점 계열 = 답으로 본 결.** 동점이면 여럿.
- **사주 쪽**: `personReading`이 이미 세는 계열 분포(`cnt`)의 최고점 계열. 동점이면 여럿.
- **비교**: 두 집합이 겹치면 **같음**(§3-B), 안 겹치면 **다름**(§3-C, 사주 1순위 × 답 1순위).
- **표시**: 인물 패널 새 덩이 「스스로 본 모습」(기본 펼침) — SELF → MATCH 또는 GAP → 상황 줄.

### ⓒ 상황 선택 — "요즘 가장 마음이 쓰이는 일"
- 성향 테스트 끝에 한 문항: 일 / 연애 / 돈 / 가족 / 딱히 없음.
- **효과 둘** — ① 해당 코너를 펼친다(일→어울리는 일, 연애→관계 스타일, 돈→돈 스타일,
  가족→힘이 되는 기운) ② 「스스로 본 모습」 끝에 §3-E 한 줄(상황 × 사주 1순위 계열).

## 2. 저장 — 노드 필드 `self` (birth 밖)

```
node.self = { answers:[{q:0..9, pick:'A'|'B'|'U'}],   // 문항 번호와 고른 것
              counts:{비겁,식상,재성,관성,인성},        // 0~4
              situation:'일'|'연애'|'돈'|'가족'|null,
              at:ISO }   또는 null
```
- **birth에 안 넣는다 [권장]** — 생년월일·시각과 성질이 다르다(시각 추정 `est`는 시각의 일부라 birth에 뒀다).
- `serializeState`·`applySeed`·`parseBackup`에 `self` 추가, **`SAVE_VER` 4→5**, `MIGRATIONS['4']`가
  `self:null`을 채운다. 백업 화이트리스트: 모양이 틀리면 파일을 거부하지 않고 `null`.
- 사람 생성 경로 셋(`ob-start`·`ptSave`·`savePerson` 새 사람)과 `addNode` 기본값에 `self:null` —
  **A7에서 밟은 것과 같은 함정**이라 `nodeBirthFieldsExplicit`처럼 `nodeSelfExplicit` 자가진단을 둔다.
- `savePerson`(수정)은 `self`를 건드리지 않는다 — birth만 바꾸므로 노드 필드는 그대로 남는다(확인 필요).
- **계정이 생기면**(B) `answers`를 그대로 서버로 옮긴다 — 설계 §6-나의 "건별 기록" 원칙.

## 3. 원고

규칙은 A6와 같다 — 공백 제외 45자 이내, 사주 용어는 계열 이름 괄호 병기만, 주어는 비워 둔다
(나/다른 사람 어디에도 맞게). 문항 머리말 앞에 화면이 "나라면 —" / "이 사람이라면 —"을 붙인다.

### A. 성향 문항 10 (계열 짝 10쌍, 앞자리 계열이 계열마다 2번씩)

| # | 짝 | 머리말 | 보기 A | 보기 B |
|---|---|---|---|---|

| Q4 | 인성·비겁 | 처음 해 보는 일을 맡으면 | 먼저 찾아보고 배운 다음 시작합니다. | 일단 부딪히며 제 식대로 익힙니다. |

인성 Q4·Q9, 식상 Q5·Q7, 관성 Q6·Q10 → 각 2번(자리 편향 없음).

MATCH/GAP 판정은 집합 겹침으로 한다. 답이 전부 "둘 다 아니에요"면 SELF 대신 D-공통의 안내 한 줄.

## 그냥 진행함
- **10문항 = 계열 10쌍 완전 배치.** 문항 수를 20~30개(R2 추정)가 아니라 10개로 줄였다 — 다섯 계열을
  짝짓는 경우가 정확히 10가지라 각 계열이 4번씩 고르게 나오고, 문항이 늘수록 이탈이 는다.
  질문을 늘리고 싶으면 같은 10쌍에 두 번째 장면을 붙이면 균형이 유지된다.
- **점수는 단순 합.** 가점 차등 없음 — 자기보고 문항에 무게를 달리 줄 근거가 없다.
- **상황은 5지선다 한 문항.** 건강은 뺐다(몸 상태를 사주로 말하는 것은 오해 소지가 크다).
- **시각 검증 결과는 저장하지 않는다.** `birth.est`와 섞이는 것을 막기 위해서다.
- **`self`는 birth 밖 노드 필드.** 생년월일 수정과 무관하게 남아야 해서다.
