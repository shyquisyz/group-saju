## 실측 (지시문 전제와 다른 것)

- 구조는 지시문대로였다 — `REL_PIECE`(10, 3250행) + `HC_PIECE`(3, 3263행) + `REL_DESC`(10, `{b,c}`, 3278행) + `relLead()`(3268행).
- **b줄·c줄은 십신 인덱스로만 갈린다.** 렌더에서 `REL_DESC[g]`만 쓰고(10071행) 합충은 `relLead(g,hcKind)`의
  a줄에만 들어간다. 그래서 표는 기본 20행이면 충분하고, 합충 조합별 변형이 없다.
- **"네 번째 줄(바로 할 수 있는 일)" 상수는 없다.** C 회차에서 `REL_TAKE`를 지우면서 "할 일 한 줄"을
  c줄 뒷문장으로 합쳤다. 지금 구조는 a·b·c 세 줄뿐이다.
  → 판정 기준 ②(d줄 중복)는 **c줄 안에서 앞문장(조심할 점)과 뒷문장(할 일)이 같은 말인지**로 바꿔 적용했다.
  대조용으로는 삭제된 `REL_TAKE` 원문 10개를 아래 (나)에 붙인다.
- 기준 ⑤ 계측: 전체 문장 **평균 22.6자, 최장 35자, 45자 초과 0개**(문장은 마침표 단위로 쪼개 셈).

### 걸린 이유 (판정 근거)
- **상관 c ①** — a줄 조각이 이미 "뒷심이 짧은 재간둥이"인데 c줄 앞문장이 "끝까지 끌고 가는 힘은
  약합니다"로 같은 말을 다시 한다. 개정안은 앞문장을 장면(벌여 놓고 눈이 감)으로 바꿔 반복을 없앴다.
- **정재 b ①** — a줄 "뿌리 깊은 살림꾼"과 b줄 "밑이 튼튼해집니다"가 같은 비유(뿌리/밑)다.
  개정안은 결과를 생활 장면(다음 달에 안 쫓김)으로 바꿨다.
- **편인 b ①** — a줄 "엉뚱한 데를 짚어 주는 스승"과 b줄 "안 보는 쪽을 짚어 줍니다"가 낱말("짚어")까지
  겹쳐 사실상 a줄을 되풀이한다. 개정안은 같은 뜻을 겪는 장면으로 바꿨다.
- **편관 c ④** — 한 문장뿐이고 생활 장면이 없다("버티는 게 힘들어지면"은 상태 서술).
  다른 아홉 개와 달리 "대신"으로 짝을 세우는 리듬도 빠져 있다. 개정안에서 둘 다 채웠다.
- **정관 b ④** — 성질만 있고 장면이 없다. 개정안은 앞에 눈에 보이는 행동(약속 시간)을 하나 붙였다.

### 걸리지 않았지만 경계선인 것 (기준 미달이라 표에는 "-"로 둠)
- **편재** — a "판돈을 키우는 큰손" / b "판을 넓힙니다": "판"이 한 번 겹친다(기준 ①은 2개 이상).
- **정관** — a "깐깐하게 지켜 주는 상사" / b "…지킵니다": "지키다"가 한 번 겹친다.
- **정인** — a "잔소리로 키우는 엄마" / c "챙김이 잔소리로 넘어오는": "잔소리"가 한 번 겹치나,
  별명의 그림자를 c에서 받는 구조라 의도된 연결로 읽힌다.
- 기준 ②(c줄 앞뒤 중복) 0건, ③(말투 이탈) 0건 — 사주·한자 용어, 설명조("경향이 있습니다"),
  흐리는 말("일 수도 있습니다"), 한 문장 비유 둘 모두 전수 확인해서 없었다.
- 기준 ⑤ 0건 — 최장 35자.

## 한눈 요약

- **유지 15행 / 손볼 것 5행** (20행 중). 기준별로는 ① 3건, ④ 2건, ②·③·⑤ 0건.
- 가장 문제 큰 3개
  1. **편인 b** — a줄과 낱말까지 겹쳐 같은 말을 두 번 한다("짚어 주는" → "짚어 줍니다").

  3. **상관 c** — a줄 "뒷심이 짧은"을 c줄에서 그대로 되풀이한다.
- 말투(기준 ③)와 길이(기준 ⑤)는 스무 행 전부 통과했다. 손볼 것은 전부 **중복**과 **장면 부족** 두 갈래다.
