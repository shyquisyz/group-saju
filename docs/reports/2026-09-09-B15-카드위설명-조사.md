# B15 — 카드 그림 위 설명 자리 재기 (조사 전용) [2026-09-09]

**`index.html`을 한 글자도 안 고쳤다.** 만든 것은 이 보고서와 `docs/현황.md` 갱신,
그리고 B13 보고서의 정정 한 문단뿐이다. 커밋·push 없음. 문장은 짓지 않았다.

각 항목에 **[사실]**(실측·원문)과 **[의견]**(판단)을 나눠 적었다.

**재는 법 —** 창 크기는 iframe으로 쟀고, **`--vvh`가 iframe 높이를 따라오는지 먼저 확인했다**
(B13이 여기서 틀렸다). 확인 결과 iframe 높이 900 → `innerHeight` 900 · `visualViewport.height` 900 ·
`--vvh` `900px`로 **셋이 일치**했다. B13은 이미 떠 있는 iframe의 높이만 바꿨던 것이 원인이다.

## 과제 1 — 캔버스 안에서 카드가 어디에 놓여 있나

### 도면 (캔버스 좌표, 단위 px) **[사실]**

```
 x=0                                                          x=1080
 ┌──────────────────────────────────────────────────────────────┐ y=0
 │                    ↕ 위 여백 30  (배경만)                     │
 │  ┌────────────────┐        ┌────────────────┐                │ y=30
 │  │                │  ↔32   │                │                │
 │  │   왼쪽 카드     │        │   오른쪽 카드    │                │
 │  │   494 × 905    │        │   494 × 905    │                │
 │  │                │        │                │                │
 │  └────────────────┘        └────────────────┘                │ y=935
 │ ↔30                                                     30↔  │
 │                    ↕ 30  (딱지가 있으면 리본 62 + 30)          │
 │  사주은하 (62px)                                              │ y=965~1095
 │  shyquisyz.github.io/group-saju (42px)                       │
 │                    ↕ 아래 여백 30                             │
 └──────────────────────────────────────────────────────────────┘ y=1125
```

| 항목 | 값 |
|---|---|
| 캔버스 | **1080 × 1125** (합충 딱지가 있으면 **1080 × 1217** — 리본 62 + 여백 30이 더 붙는다) |
| 왼쪽 카드 | x **30**, y **30**, 폭 **494**, 높이 **905** |
| 오른쪽 카드 | x **556**, y **30**, 폭 **494**, 높이 **905** |
| **위 여백** | **30px** |
| 좌 여백 / 우 여백 | 30 / 30 |
| 두 카드 사이 | **32** |
| 카드 아래 ~ 캔버스 끝 | **190** (= 여백 30 + 서명 블록 130 + 여백 30) |

### 위 여백에 무엇이 그려져 있나 **[사실]**

**배경뿐이다 — 글자도 무늬도 없다.** y 0~29를 2px 간격으로 **16,200점** 훑었다.

| 구간 | 밝은 점(RGB 어느 하나 > 90) | 비율 |
|---|---|---|
| 카드 위 여백 y0~29 | **0개** | **0 %** |
| (비교) 서명 줄 y1000~1039 | 1,036개 | 4.8 % |

색 범위는 RGB 최소 (5,8,14) ~ 최대 (42,34,39) — `cardPaintBg`가 그린 어두운 우주 톤과
그 위의 비네트 그라데이션이다. 별 점이 섞여 있어 값에 폭이 있을 뿐 글자는 없다.

**눈으로도 확인했다** — 캔버스 위쪽 260px을 잘라 화면에 크게 띄우고 y=30에 눈금선을 그어 봤다.
카드 무늬 위로 **아주 얇은 검은 띠 한 줄**만 보인다. **[의견]** 두 줄은커녕 한 줄도 얹기 어려워 보인다.

### 자리를 정하는 코드 **[사실]**

| 값 | 어디에 |
|---|---|
| `CARD_W = 1080` | 2181행 |
| `CARD_B.margin = 30` (위·좌·우·아래 여백) | 2199행 근처 `CARD_B` |
| `CARD_B.gap = 32` (두 장 사이) | 〃 |
| `CARD_B.th = 905` (카드 높이) | 〃 |
| `CARD_W_PANEL = 494` (카드 폭) | `Math.floor((CARD_W − margin*2 − gap)/2)` |
| 카드 좌표 계산 | **`cardGeom()`** (2387행) — `{tw, th, top:B.margin, x0, ribbonY}` |
| 그리기 명령 만들기 / 실제로 그리기 | **`cardPlan(a,b)`** / **`cardPaint(ctx,plan,…)`** |
| 캔버스 높이 | `plan.h` = `footTop(965) + footerH(130) + margin(30)` |

## 과제 2 — 카드 한 장 위에 글자가 몇 자 들어가나

### 폭과 배율 **[사실]**

| 항목 | 값 |
|---|---|
| 카드 한 장 폭 (캔버스 좌표) | **494px** |
| 미리보기 배율 | **0.452** (캔버스 1080 → 화면 488) — **폭 600과 1024가 같다**(시트가 560으로 묶여 있다) |
| 화면에서 카드 한 장 폭 | **223px** |
| 화면에서 카드 위 여백 | **14px** (30 × 0.452) |

### 글자 크기별 한 줄 글자 수 **[사실]**

재는 법: 공백 없는 한글 28자(`가나다라마바사…`)를 그 글꼴·크기로 재어 **한 자 폭**을 내고 폭으로 나눴다.
그리고 **실제 설명 문장 열 개**를 하나씩 재어 몇 개가 한 줄에 드는지 함께 셌다.

**캔버스에 그릴 때** (카드 폭 494 기준, 카드 글꼴 weight 600)

| 크기 | 한 자 폭 | 한 줄 글자 수 | 문장 열 개 중 한 줄에 드는 것 | 가장 긴 문장 폭 |
|---|---|---|---|---|
| **24px** | 20.74 | **23자** | **10 / 10** ✅ | 475 |
| 28px | 24.20 | 20자 | 7 / 10 | 555 |
| 32px | 27.66 | 17자 | 2 / 10 | 634 |

**[사실] 24px이면 열 문장이 전부 카드 폭 안에 한 줄로 들어간다** — 두 줄이 필요 없다.
(다만 앞에 이름까지 붙이면 `구성원A — 갓 쓴 두 사람이…`가 24px에서 **589px**로 494를 넘는다.)

**화면에만 얹을 때** (카드 한 장 폭 223 기준, 본문 글꼴 weight 400)

| 크기 | 한 자 폭 | 한 줄 글자 수 | 문장 열 개 중 한 줄에 드는 것 | 가장 긴 문장 폭 |
|---|---|---|---|---|
| 11px | 9.5 | 28자 | **10 / 10** ✅ | 219 |
| 12px | 10.37 | 26자 | 8 / 10 | 239 |
| 13px | 11.24 | 24자 | 4 / 10 | 259 |
| 15px | 12.96 | 21자 | 0 / 10 | 299 |

(설명 문장은 22~28자다.)

### 두 줄에 필요한 세로 · 위 여백 30px에 드나 **[사실]**

| 크기 | 한 줄 세로 | **두 줄 세로** | 위 여백 30에 두 줄이 드나 | 모자란 양 |
|---|---|---|---|---|
| 캔버스 24px | 31 | **62** | **모자란다** | 32px (카드와 10px 띄우면 **42px**) |
| 캔버스 28px | 36 | **72** | 모자란다 | 42px (띄우면 52) |
| 캔버스 32px | 42 | **84** | 모자란다 | 54px (띄우면 64) |

**한 줄이어도 모자란다** — 24px 한 줄이 31px인데 여백은 30px이라 **1px 모자라고**, 그러면
글자가 카드 윗변에 딱 붙는다. 띄우는 간격까지 보면 24px 한 줄에 **약 11px**이 더 필요하다.

## 과제 3 — 저장되는 카드에 사람 이름이 이미 들어가 있나

### **예, 들어간다.** **[사실]**

명패 맨 윗줄이 그것이다 — 두 장 모두, **24px**로.

| 어디 | 글자 예 | 크기 |
|---|---|---|
| 왼쪽 카드 명패 윗줄 | `내가 보는 구성원A` | 24px |
| 오른쪽 카드 명패 윗줄 | `구성원A가 보는 나` | 24px |

본인이 안 낀 관계에서는 양쪽 다 이름이 들어간다(`구성원A가 보는 구성원D` 꼴, B⑫).

### 지금 카드에 글자로 그려지는 것 전부 **[사실]** (합충 없는 쌍 = 12개 op)

| 무엇 | 크기 | 자리 |
|---|---|---|
| 명패 윗줄 (**이름 포함**) ×2 | 24px | 카드 안, 가운데 |
| 별명 ×2~6줄 | 52px | 카드 안, 가운데 |
| 명패 아랫줄 (물상 + 지지, 예 `큰 산 子`) ×2 | 26px | 카드 안, 가운데 |
| 서명 `사주은하` | 62px | 캔버스 왼쪽 아래 |
| 주소 `shyquisyz.github.io/group-saju` | 42px | 그 아래 |
| (합충이 있을 때만) 딱지 리본 `죽이 잘 맞는 사이` | 42px | 두 카드 아래 가운데 |

**[의견]** 그러므로 "카드 위에 이름을 붙이면 공유할 때 실명이 나가는가"의 답은 —
**이미 나가고 있다.** 설명 줄에 이름을 붙여도 **새로 생기는 위험은 없다.**
다만 이름이 카드당 두 번(명패 + 설명) 나오게 되니 그건 보기의 문제다.

## 과제 4 — 넣는 방법 세 가지 견주기

| 방법 | 자리가 있나 | 한 줄 글자 수 | 카드 높이 905 | 저장 그림에 나가나 | 손댈 곳 |
|---|---|---|---|---|---|
| **㉮ 캔버스 안** (카드 위) | **조건부 가능** — 지금 위 여백 30px으로는 한 줄도 1px 모자란다. **캔버스를 키우면 된다** | 24px에 **23자**, 문장 **10/10** 한 줄 | **안 바뀐다** ✅ | **나간다** (이미 이름도 나감) | `cardGeom()`의 `top`, `cardPlan`의 op 추가, `plan.h` |
| **㉯ 화면에만** (미리보기 위) | 카드 **위에 겹쳐** 놓기는 **자리 없음**(14px뿐, 두 줄 39px에 **25px 모자람**) / 미리보기 **위쪽에 한 줄짜리 두 칸**으로 두면 **가능** | 11px에 **28자**, 문장 **10/10** (12px는 8/10, 13px는 4/10) | 안 바뀐다 ✅ | **안 나간다** | HTML 한 덩이 + CSS(2단) |
| **㉰ 지금 그대로** (카드 아래 두 줄) | **이미 있다**(B14) | 13px에 **37자** — 전 폭을 쓰므로 넉넉 | 안 바뀐다 ✅ | 안 나간다 | 없음 |

### ㉮를 하려면 캔버스를 얼마나 키워야 하나 **[사실]**

카드 위에 `여백 30 + 글줄 + 간격 10`을 두는 셈으로 —

| 얹는 것 | 새 카드 y | 새 캔버스 높이 | 늘어나는 양 |
|---|---|---|---|
| 24px **한 줄** | 30 → **71** | 1125 → **1166** | **+41** |
| 24px 두 줄 | 30 → **102** | 1125 → **1197** | +72 |
| 28px 한 줄 | 30 → **76** | 1125 → **1171** | +46 |

**카드 높이 905는 그대로다** — 늘어나는 것은 캔버스뿐이다. 분기표대로 **「조건부 가능」**.
**[의견]** 카드가 세로로 길어지면 카톡 미리보기에서 더 작게 줄어든다 — 그건 실기기로 봐야 안다.

### ㉯의 실측 한 가지 더 **[사실]**

지금 설명 블록은 **두 줄이 세로로 쌓여** 38 + 아래 여백 14 = **52px**을 쓴다.
같은 내용을 **한 줄짜리 두 칸(왼쪽·오른쪽)**으로 바꾸면 한 줄 높이 ≈ 18 + 여백 14 = **32px** —
**오히려 20px이 남는다.** 지금 시트는 내용 821 / 상한 828로 **7px 여유**가 있으므로,
바꿔 얹는 것은 넘침 없이 된다(폭 600·1024 모두 같은 값).
다만 칸 하나가 223px이라 **글꼴을 11px까지 내려야 열 문장이 다 한 줄에 든다**(12px면 8/10).

## 다음에 정할 것 **[의견]**

1. **㉮로 갈지 ㉯로 갈지.** 카드 그림 자체에 설명을 넣고 싶다면 ㉮(+41px)가 답이고,

2. **㉮로 간다면 이름을 붙일지.** 이름까지 붙이면 24px에서 589px로 카드 폭 494를 넘는다 —
   이름을 빼거나(문장만) 글자를 더 줄여야 한다. 이름은 이미 명패 윗줄에 있다.
3. **㉯로 간다면 11px이 너무 작지 않은지** — 폰에서 사람이 봐야 안다.
