## 분기표 C를 따르지 않은 판단 — 근거와 함께

치환 직후 자가진단이 **56/58**로 떨어졌다. 실패 둘 —
`cnrPowerEven` / `cnrPowerExtremeFull`.

분기표 C는 "그 항목만 원상 복구"지만, **원인이 치환이 아니라 자가진단 쪽이었다.**
두 시험은 옛 문구를 문자열로 박아 두고 대조한다:

- `txt(evenWeak).indexOf('다섯 기운을 고루 갖춘 판입니다')>=0`
- `txt(ex2).indexOf('어느 쪽 사람과도 잘 어울립니다')>=0`

보는 동작("다섯이 고루면 고루 문장이 나오는가" / "극약+고루면 해석 층을 생략하는가")은 그대로다.
승인된 문구를 되돌리면 이번 회차의 목적이 뒤집히므로, **대조 문자열만 새 문구로 갱신**하고
왜 바꿨는지 취소선 주석을 달았다(9441·9448행 부근). 갱신 후 **58/58**.

## 그 밖에 판단해서 정한 것

1. **`<b>` 강조 처리** — 개정안 표에는 마크업이 없다. 낱말이 그대로 남은 곳은 강조를 지켰고,
   문장이 새로 쓰인 곳은 개정안 그대로(강조 없이) 넣었다.

   | # | 처리 |
   |---|---|
   | ③49 `<b>어디에 쓸지를 정하는 것</b>` | 문장이 바뀌어 **강조 삭제** |
   | ③52 `<b>곁의 사람과 환경을 적극적으로 쓰는 편</b>` | 문장이 바뀌어 **강조 삭제** |
   | ④56 `<b>타고난 무기가 아니라는 뜻</b>` | 같은 낱말이 남아 **강조 유지** |
   | ⑧93·96 `<b>오행 이름</b>` | 개정안이 〈오행〉 자리표시자라 **강조 유지** |
   | ③51(신약) `<b>사람과 자리를 빌려 쓰는 쪽</b>` | 유지 판정 문장이라 손대지 않음 |

2. **④ 55번 문장 쪼개기 구현** — 개정안이 "(한 문장을 둘로 쪼갠다)"만 적어 두어 실제 코드는
   이렇게 짰다:
   `반면 ${NUM_KO[letters]} 글자 안에 하나도 없는 갈래가 ${NUM_KO[zeros.length]}입니다.`
   + `${j.t}${particle(j.base,'이가')} 그렇습니다.`
   결여 갈래가 하나뿐이면 **"…갈래가 하나입니다."**가 되어 조금 어색하다. 개정안에 다른 지시가
   없어 그대로 뒀다.

3. **주석 정정 둘** — 코드 변경 아님.
   - 3385행 `[문안] 사용자가 준 것 그대로다. 임의 수정 금지.` → 취소선 + **[2026-09-09 Teo 승인으로 C8에서 개정함]**,
     무엇을 몇 건 바꿨는지와 원문이 남아 있는 보고서 경로를 적었다.
   - 3517행 `판정 이름 뒤에 "셋 중 몇"을…` → 괄호에서 판정 이름을 뺐으므로 취소선 + C8 정정 줄.
   - 2718행의 `임의 수정 금지`는 합충 문안(`HC_DEF`)이라 **손대지 않았다** — 여덟 코너가 아니다.

4. **손대지 않은 것** — 계열 이름 괄호, ①의 물상 앞도막 10개, ⑧ `EL_TRAIT`(그룹 패널 공용).
