### (3) `blk()` 조립 자리 확정

함수는 `pairReading(a,b,giver,receiver,rel,collapse)`(회차 시작 시점 기준 10285행 부근) 안의
지역 함수다.

```js
const blk=(lead,g,hcKind)=>{
  const d=REL_DESC[g];
  return `<div class="nickblk"><div class="nicklead">${lead}</div>`
    +`<div class="nickname">${REL_NICK[g]}</div>`
    +`<div class="nickdesc">${relLead(g,hcKind)} ${d.b} ${d.c}</div></div>`;};
const hcKind=(hapChung(a,b)||{}).kind||null;
let t1=blk(`${a.name}에게 <b>${b.name}</b>은는`,gAB,hcKind)
      +blk(`<b>${b.name}</b> 입장에서는`,gBA,hcKind)
```

- ㉠ 첫 문장 자리 — `relLead(g,hcKind)`가 만드는 문자열. blk() 안에서 `${relLead(...)}`.
- ㉡ 좋은 점(b) 자리 — 바로 뒤 `${d.b}`. **조각은 이 둘 사이**에 들어간다.
- ㉢ 누구를 설명하는가 — **`a`,`b`는 항상 (나, 상대) 순서로 들어온다**(아래 (4) 참고).
  첫 `blk` 호출은 `gAB=relGod(a,b)`로 **b(상대)를 설명**하고, 둘째 `blk` 호출은
  `gBA=relGod(b,a)`로 **a(나)를 설명**한다 — A1 보고서의 "위 문단=상대, 아래 문단=나"가
  실제 변수와 정확히 일치했다.

## 2단계 · 구현

### (1) 조각 표 — `HC_PIECE` 바로 아래

```js
const GANG_PIECE={
  '극왕':'기운이 넘치도록 두터워서, 쓰고도 늘 남습니다.',
  '신강':'기운이 든든한 편이라, 웬만한 일에는 흔들리지 않습니다.',
  '신약':'기운이 넉넉한 편은 아니라, 무리가 쌓이면 티가 납니다.',
  '극약':'기운을 아껴 써야 하는 편이라, 자리가 받쳐 줄 때 제 몫이 납니다.'};
```

지시문이 준 문구를 그대로 썼다(극왕 문장이 A1 초안의 "…끄떡없습니다"에서
"…쓰고도 늘 남습니다"로 바뀌어 있었다 — A1이 지적한 상관("뒷심이 짧은")과의 충돌을
Teo가 이미 손본 것으로 보고, 그대로 채택했다).

### (2) 함수 시그니처 확장 + 삽입

```js
function pairBlock(a,b,collapse,withStrength){
  ...
  return {rel, giver, receiver,
    reading:pairReading(a,b,giver,receiver,rel,collapse,withStrength), ...};}

function pairReading(a,b,giver,receiver,rel,collapse,withStrength){
  ...
  const blk=(lead,g,hcKind,person)=>{
    const d=REL_DESC[g];
    const gv=withStrength?personGangyak(person):'';
    const gang=gv?(' '+GANG_PIECE[gv]):'';
    return `<div class="nickblk">...`
      +`<div class="nickdesc">${relLead(g,hcKind)}${gang} ${d.b} ${d.c}</div></div>`;};
  const hcKind=(hapChung(a,b)||{}).kind||null;
  let t1=blk(`${a.name}에게 <b>${b.name}</b>은는`,gAB,hcKind,b)   /* person=b(상대) */
        +blk(`<b>${b.name}</b> 입장에서는`,gBA,hcKind,a)          /* person=a(나) */
  ...
```

- `person` 인자로 "누구를 설명하는 문단인가"를 명시적으로 넘긴다 — 새로 계산하지 않고
  `gAB`/`gBA`가 이미 가리키는 사람을 그대로 따른다.
- `withStrength`가 꺼져 있으면 `gv=''`, `gang=''`이 되어 **원래 문자열과 완전히 같은 결과**가
  나온다(인물 패널 무수정 보장의 근거).
- `personGangyak()`이 빈 문자열이면(분기 D) `gv`가 falsy라 `gang`도 `''`이 되어 조각이
  통째로 생략된다 — 별도 분기 코드 없이 같은 삼항식이 D도 처리한다.

### (3) 관계 패널 호출부만 켠다

```js
const PB=pairBlock(e.a,e.b,undefined,true);   /* [2026-09-09 A2] 관계 패널에서만 기운 세기 조각을 켠다 */
```

인물 패널 호출부(`pairBlock(meNode,n,PAIR_FOLD)`)는 **한 글자도 안 건드렸다**.

### 3. 생년월일 없는 사람이 낀 표본 — 분기 D

`birth:null`인 가짜 상대를 만들어 `pairReading(me, fakeOther, ..., withStrength=true)`를
직접 호출했다. `personGangyak(fakeOther)`가 빈 문자열을 돌려주고, 해당 문단만 조각이
빠졌다 — **공백 두 칸·마침표 겹침 없이 깨끗하게** 이어졌다:

> …엉뚱한 데를 짚어 주는 스승 같은 존재**입니다. 며칠** 붙잡고 있던 문제가…

(← 세기 조각이 없어도 "입니다." 뒤에 정확히 한 칸 띄고 b줄이 이어진다.)

비어도 나머지 한쪽은 정상 작동함을 함께 확인했다.
