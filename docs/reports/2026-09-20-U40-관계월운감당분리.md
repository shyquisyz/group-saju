# U40 — 관계·월운·감당력 분리 [2026-09-20]

- 실행 모델: Opus 5 — 계산 경로 설계 변경 + 검증 회차라 적정.
- [비용 수준: 중 — 함수 4개 신설, 월운 판정 교체, 문구 20여 곳, 표본 7,200달 문턱 재측정, 자가진단 1개]
- 사용자: "U40 방향은 그대로 진행하되 네 가지를 수정해서 구현" + 점수 모듈은 heuristic임을 명시 + 합·충·형 다섯 단계 분리.
- 테스트 인물: 구성원A(丙寅 辛丑 壬午 己酉, 남) — 메모리 계산.

## 구현
1. **관계 ≠ 돈 경로** — `relationTrace(r, 기둥, 성별)`. wealth(`luckForceTrace` 재성)와 다른 함수다.
   - 신호: 짝 별 활성(SPOUSE_STAR_STEM/BRANCH) · 배우자 자리(일지) 활성(SPOUSE_PALACE_CHUNG/YUKHAP/HYEONG/COMBO) · 일간 합(DAYMASTER_GANHAP).
   - 평생 흐름의 관계 곡선이 이것을 쓴다. 두 숫자가 우연히 같아도 오류로 보지 않는다.
   - 자가진단 **relationPath**는 숫자가 다른지 보지 않는다. 대신 확인하는 것:
     - 별칭이 아닌지(다른 함수·다른 소스)
     - 근거 코드 구성(관계 = SPOUSE_*/DAYMASTER_*, 돈 = ACT_*)
     - 일지 충이 있고 재성이 0인 가상 기둥(壬子)에서 관계 > 0 · 돈 = 0
2. **월운 세 지표 = 서비스 내부 heuristic** — moneyActivity(재성+식상×.5) · recoveryLearning(인성+비겁×.5) · changePressure(관계 발견 가중 합 + 대운·세운 지지 충).
   - **합도 변화에 들어간다.** 합 = 좋음·충 = 나쁨 환산을 없앴다.
   - 문턱: 무작위 600명 × 12달의 75백분위(1.15 / 1.18 / 1.5) → 각 표시 25.7% · 23.8% · 25.9%.
   - 화면은 「돈·활동」「편한 달」(회복·배움이면서 변화가 아닐 때)「변화」. ~~좋은 달·조심할 달·예민한 달~~은 12달 표·그룹 보고서·렌즈·은하 ✨/⚡ 모든 경로에서 바꿨다.
3. **activation과 capacity 분리** — `luckForceTrace`는 일간 강약을 읽지 않는다(자가진단이 함수 본문에 gangyak·verdict가 없음을 확인). 감당은 `themeCapacity`(CAP_EASY/HEAVY/OVER/EVEN). 대운 문장은 "…기운이에요. 감당으로 보면 …" 두 문장으로 나눴다. activation을 "좋은 운"으로 쓰는 곳은 없다.
4. **자식 규칙 명시** — 남성 관살 · 여성 식상 = 자녀별 중 하나의 기준, 시주·시지 = 자녀 자리. 「자식은?」 끝에 "학파마다 다르게 보기도 해요". 다른 체계와 섞지 않는다.
- **점수 모듈 머리 주석 + `docs/점수-heuristic.md`**: "본 점수는 전통 명리의 공식 수치가 아니라 여러 명리 신호의 상대적 활성도를 비교하기 위한 서비스 내부 heuristic이다." UI에는 수치를 보이지 않는다.
- **합·충·형 다섯 단계**:
  - `detectInteractions`(①관계 ②natalPos ③area — 해석·점수 없음. 자가진단이 good/bad/score 필드가 없음을 확인)
  - ④ activation·capacity
  - ⑤ 문장
  - 합을 "좋아요"로 옮기던 문장 아홉(NOW_HIT 합 넷 · DAY_HIT 육합 · NOW_MONTH_HIT 합 둘 · 같이 겪은 해 "반가운 변화")을 "묶여서 …가 늘기 쉬워요 / 얽히기 쉬워요"로 바꿨다.
