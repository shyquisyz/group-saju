## 1. 프로젝트 개요

### 1.1 서비스명

- **[확정] 사주은하**
- 현재 공개 데모: https://shyquisyz.github.io/group-saju/
- 기존 화면 표기: `STELLAR 0.7`

### 1.2 한 문장 정의

> 사람을 행성으로, 사람 사이의 사주 관계를 연결선·고리·궤도로 보여주고, 현재 누구와 어떻게 관계를 맺으면 좋은지 알려주는 관계형 사주 서비스.

### 1.3 해결하려는 문제

기존 사주 서비스는 주로 한 사람의 성격과 운세를 긴 텍스트로 풀이한다. 사주은하는 다음 질문을 시각적으로 이해하고 행동으로 옮기게 하는 것을 목표로 한다.

- 이 사람과 나는 왜 잘 맞거나 부딪치는가?
- 내 주변에서 나에게 도움을 주는 사람은 누구인가?
- 내가 도움을 주는 사람은 누구인가?
- 그룹 안에서 가장 잘 맞는 사람과 갈등 가능성이 있는 사람은 누구인가?
- 이번 달에는 어떤 관계가 강해지거나 약해지는가?
- 연애·재물·일·인간관계에서 언제 무엇을 하면 좋은가?

### 1.4 핵심 차별점

- 사주를 표와 긴 설명이 아니라 3D 은하로 표현
- 개인 운세보다 **사람 사이의 관계**를 중심으로 구성
- 개인 두 명뿐 아니라 가족·친구·직장 등 여러 사람의 관계를 한 화면에서 비교
- 초대받은 사람이 자기 정보를 직접 연결해 공동 은하를 완성
- 월별 시간 변화가 행성의 상태와 관계 해석에 반영
- 한 번 보고 끝나는 궁합이 아니라 관계 관리 도구로 확장

### 1.5 제품이 사용자에게 줘야 하는 가치

1. **발견**: 우리 관계가 어떤 구조인지 파악
2. **이해**: 왜 편하거나 부딪치는지 설명
3. **행동**: 지금 무엇을 하면 좋은지 안내
4. **재방문**: 절기·월이 바뀌면 달라진 관계를 다시 확인

## 2. 최종 사업 목표

### 2.1 장기 목표

**[확정]** 단기간 매각보다, 시간이 걸리더라도 이용자와 결제가 계속 누적되는 구조를 지향한다. 한 사용자가 다른 사람을 초대하고, 초대받은 사람이 다시 자기 그룹을 만들며, 월별 변화 때문에 모두가 재방문하는 복리형 성장이 목표다.

성장 순환:

1. 사용자가 자신의 은하 생성
2. 주변 사람을 그룹으로 초대
3. 초대받은 사람이 무료 가입하고 자기 행성 연결
4. 그룹 결과가 풍부해짐
5. 구성원 중 한 명이 공동 분석 결제
6. 다른 구성원들이 유료 결과의 가치를 경험
7. 각 구성원이 개인 상세 분석 결제 또는 새 그룹 생성
8. 다음 달 관계 변화 알림으로 재방문
9. 토큰 소진 후 재구매

### 2.2 핵심 성장 조건

- 초대 과정은 최대한 무료이고 간단해야 함
- 무료 이용만으로 서비스의 차이를 충분히 경험해야 함
- 결제는 사람을 모으는 행위보다 의미 있는 해석을 얻는 순간에 발생해야 함
- 매달 결과가 실제로 달라지고, 사용자가 이를 이해할 수 있어야 함
- 한 사람의 결제가 그룹의 다른 사람에게 다음 결제 이유를 보여줘야 함

## 5. 제품 구조

### 5.1 개인 은하

사용자가 직접 사람을 등록하고 개인적으로 관리하는 공간.

- **[확정]** 본인 포함 총 3명 무료
- 정확한 표현: 본인 1명 + 상대 2명 무료
- **[확정]** 그 이후 사람 추가는 토큰 소비
- **[확정]** 사람 한 명 추가 비용은 러프하게 3토큰 고려 중
- 개인 은하의 상세 관계 내용은 본인만 열람
- 그룹에 있는 사람을 개인 은하로 가져올 때 무료 범위 또는 유료 등록 규칙 적용

### 5.2 공유 그룹

여러 사용자가 초대로 참여하고 각자 자신의 행성을 연결하는 공동 공간.

- **[권장]** 그룹 생성 무료
- **[권장]** 그룹 초대와 참여 무료
- **[권장]** 그룹 기본 행성 지도 무료
- **[권장]** 상세 그룹 분석·월별 변화·개인 상세 관계는 토큰 사용
- 그룹에 참여했다고 모든 구성원이 개인 은하에 무료 등록되는 것은 아님
- 그룹에서는 공동 배치와 제한된 기본 정보만 확인
- 특정 구성원을 개인 은하에 저장하거나 상세 분석할 때 별도 규칙 적용

### 5.3 개인 정보와 수정

- **[확정]** 이름 수정 가능
- **[확정]** 출생시간 수정 가능
- **[확정]** 출생도시 수정 가능
- **[확정]** 그룹 수정 가능
- **[확정]** 생년월일은 원칙적으로 수정 불가
- **[확정]** 생년월일을 수정하게 한다면 토큰 소비 예정
- **[권장]** 최초 1회 또는 등록 후 24시간 동안 출생정보 무료 수정
- **[권장]** 이후 생년월일·시간·도시처럼 계산 결과를 바꾸는 정보는 `출생정보 재계산` 1토큰으로 통합
- 이름·그룹명처럼 계산에 영향을 주지 않는 정보는 무료 수정

주의: 출생시간과 출생도시도 계산 방식에 따라 결과에 영향을 줄 수 있다. 생년월일만 유료 수정으로 묶는 것이 명리 계산 논리와 충돌하지 않는지 검토한다.

## 6. 초대 및 연결 시스템

### 6.1 개인 초대

- **[확정]** 개인 생년월일·출생시간·출생도시를 일회용 코드로 내보내 서로 추가할 수 있게 함
- 상대가 참여하기 전에는 반투명 행성으로 표시
- 상대가 직접 참여하고 정보를 확인하면 정상 행성으로 전환
- 코드는 추측하기 어려운 값으로 생성
- 코드 만료, 폐기, 재발급 지원
- 초대받은 사람은 공개될 정보 범위를 확인하고 동의해야 함

### 6.2 그룹 초대

**[권장]** 여러 명이 참여해야 하므로 완전한 일회용 코드 한 개보다 제한형 초대 링크를 사용한다.

제공 방식:

- 카카오톡 등으로 공유할 수 있는 링크
- 직접 입력하는 6자리 코드
- QR코드(휴대전화 카메라로 스캔하는 사각형 링크)

관리 옵션:

- 유효기간: 24시간, 7일, 직접 종료
- 최대 참여 인원
- 즉시 참여 또는 관리자 승인
- 링크 폐기와 재발급
- 계정별 1회 사용

### 6.3 초대받은 사용자의 흐름

1. 초대 링크 열기
2. 그룹 이름·종류·현재 인원 확인
3. 간편 회원가입 또는 로그인
4. 자신의 출생정보 입력
5. 개인정보 공개 범위 선택
6. 그룹에 본인 행성 생성
7. 기본 역할과 관계 일부 확인
8. 개인 은하 생성 또는 상세 분석 제안

가입·그룹 참여·기본 결과 확인 단계에서 결제를 요구하지 않는다.

### 6.4 초대 보상

**[권장]** 링크를 보내기만 해서는 보상하지 않는다.

- 초대받은 사람이 가입하고 출생정보 입력 완료
- 그룹 참여자가 3명에 도달하면 생성자에게 1토큰 또는 그룹 분석 1회 체험권
- 5명에 도달하면 그룹 타임라인 1회 체험 가능

## 8. 사주 시각화 체계

### 8.1 핵심 원칙

> 행성 본체는 사람, 고리는 관계 구조, 연결선은 오행 흐름, 날씨·빛·움직임은 시간 변화, 투명도는 정보 연결 상태를 의미한다.

하나의 시각 속성에 서로 다른 의미를 중복 배정하지 않는다.

### 8.2 시각 요소별 의미

| 시각 요소 | 의미 |
|---|---|
| 행성 본체 | 개인의 타고난 성질 |
| 행성 색상·재질 | 오행·음양 등 개인 속성 |
| 행성 사이 연결선 | 생·극·비화 등 오행 흐름과 방향 |
| 금색의 매끈한 고리 | 합(서로 끌리거나 결속되는 관계) |
| 끊어진 붉은 고리 | 충(서로 부딪치며 변화를 만드는 관계) |
| 서로 직각인 금색·붉은 고리 | 합과 충이 함께 있는 복합 관계 |
| 120도 구조 | 삼합(세 사람이 모여 하나의 강한 흐름을 만드는 관계) |
| 고리 두께 | 관계 작용의 강도 |
| 고리 밝기·맥박 | 현재 시기에 활성화된 정도 |
| 행성 꼬리 | 역마(이동·변화·환경 전환의 기운) |
| 먹구름 | 현재 시기의 일시적 압박·갈등 |
| 반투명 행성 | 상대가 아직 직접 확인하지 않은 일방 추가 상태 |
| 입자 흐름 | 사람 사이 에너지의 방향 |
| 오라·입자 | 귀인·연애·재물·직업 등 긍정적 활성 영역 |
| 흔들리는 궤도 | 현재 시기의 불안정성 |

### 8.3 고리 규칙

- 고리 없음: 주요 합·충이 두드러지지 않음
- 얇은 고리: 관계 구조가 존재함
- 두꺼운 고리: 원국에서 반복되거나 현재 강하게 체감되는 작용
- 밝아지거나 맥박치는 고리: 이번 달처럼 일시적으로 활성화
- 같은 종류의 반복 고리는 최대 2개 정도로 제한해 복잡도를 억제
- 기존의 `여러 그룹에 속하면 고리 3개` 규칙은 제거 권장
- 120도 삼중 고리는 단일 인물의 장식보다 실제 삼합을 이루는 세 행성의 공동 구조로 표현 권장

### 8.4 시간 상태 표현

- 꼬리와 먹구름은 영구적인 사람 평가로 사용하지 않는다.
- 먹구름은 `나쁜 사람`이 아니라 이번 시기의 충·형·파·해 활성처럼 일시적인 압박을 뜻한다.
- 역마가 원국에 있으면 짧고 약한 꼬리, 현재 월운에서 활성화되면 길고 움직이는 꼬리로 표현 가능
- 운세 상태를 색만으로 구분하지 말고 형태·움직임을 함께 사용해 색각 이상 사용자도 구분할 수 있게 한다.

### 8.5 잠금 상태와 초대 상태 구분

반투명 행성은 초대 미확인 상태에 사용하므로 유료 잠금 상태에 중복 사용하지 않는다.

유료 잠금 권장 표현:

- 빈 궤도 안에서 행성 윤곽만 빛남
- 표면이 보이지 않는 어두운 실루엣
- 관계선 일부만 보이고 결과는 가림

## 13. 복리형 성장 측정

### 13.1 성장 계산 개념

다음 달 사용자 수는 대략 아래 두 집단의 합이다.

- 이번 달 사용자 중 다음 달에도 돌아온 사람
- 이번 달 사용자가 초대해 새로 들어온 사람

예시:

- 사용자 1명이 평균 2명 초대
- 초대받은 사람 중 30% 가입 → 사용자당 신규 0.6명
- 기존 사용자 중 다음 달 재방문 50% → 기존 0.5명 유지
- 합계 1.1명 → 월 10% 성장 가능

`성장계수`는 이번 달 사용자 1명이 다음 달 몇 명의 활성 사용자를 만드는지를 뜻한다. 이 수치가 1보다 커야 광고 없이도 이용자가 누적된다.

### 13.2 필수 측정 사건

분석 도구에서 최소한 다음 행동을 기록한다.

- 첫 방문
- 본인 정보 입력 완료
- 첫 상대 추가 완료
- 무료 3명 구성 완료
- 그룹 생성
- 초대 링크 생성
- 링크 공유
- 초대받은 사용자 가입
- 그룹 참여 완료
- 유료 미리보기 노출
- 토큰 구매 시작·완료·실패
- 토큰 기능 사용
- 공동 분석 개방

검증 방법:

1. 계산 기준을 문서로 명시
2. 여러 만세력과 대표 생년월일 결과 비교
3. 경계 시각, 윤달, 해외 출생 등 예외 테스트
4. 명리 전문가 검수
5. 계산 결과와 해석 문장을 분리
6. 사용자가 필요할 때 근거를 확인할 수 있게 제공

AI 역할:

- 계산된 결과를 이해하기 쉽게 설명
- 그룹 종류와 질문 맥락에 맞게 행동 조언 생성
- 근거 없이 새로운 사주 결과를 만들어내지 않음
- 같은 입력에 핵심 결론이 뒤집히지 않도록 규칙 기반 결과를 우선

## 16. 결제와 토큰 원장

`토큰 원장`은 토큰이 언제 충전되고 사용·환불됐는지를 변하지 않는 기록으로 남기는 장부다.

필수 요구사항:

- 결제 성공을 클라이언트 화면만 믿지 않고 서버에서 검증
- 토큰 충전·사용·환불을 원장에 각각 기록
- 같은 결제 또는 사용 요청이 중복 처리되지 않게 함
- 잔액이 음수가 되지 않음
- 실패한 분석에는 토큰이 소비되지 않거나 자동 복구
- 관리자도 임의 수정 대신 지급·회수 기록을 남김
- 결제 취소와 부분 환불 정책
- 미성년자 결제 정책
- 전자상거래 고지, 이용약관, 개인정보 처리방침 준비

- 입력 중 자동 저장과 복구

- 네트워크 재시도와 중복 저장 방지

### 18.3 보안

- 사용자 입력을 `textContent` 또는 안전한 렌더링 방식으로 표시
- HTML 삽입이 필요한 경우 검증된 정화 처리
- CSP 적용
- 외부 스크립트 버전 고정과 무결성 확인
- 비밀키를 클라이언트 코드에 넣지 않음
- 서버 권한 검사
- 초대 코드 무작위성·만료·사용 제한
- 결제 웹훅(결제사가 서버에 결과를 알려주는 요청) 서명 검증
- 보안 헤더 적용

## 21. MVP 완료 조건

다음 조건을 모두 만족해야 `데모가 아닌 출시 가능한 1차 제품`으로 본다.

- 신규 사용자가 도움 없이 본인을 등록할 수 있음
- 상대 2명을 무료로 등록하고 세 행성을 확인할 수 있음
- 각 시각 요소의 의미가 화면 설명과 일치함
- 관계 결과가 단순 점수가 아니라 이유와 행동 조언을 포함함
- 계산이 기준 만세력과 대표 테스트 데이터에서 일치함
- 사용자가 그룹 링크를 만들어 다른 계정을 초대할 수 있음
- 초대받은 사람이 자신의 정보 공개에 동의하고 참여할 수 있음
- 토큰 13개를 구매하고 정확히 충전됨
- 4번째 인물 또는 유료 분석에서 토큰이 정확히 차감됨
- 중복 클릭·새로고침에도 이중 차감되지 않음
- 결제 실패 시 토큰이 잘못 지급되지 않음
- 계정 삭제와 그룹 탈퇴가 정상 동작함
- 모바일 주요 기기에서 화면이 깨지지 않음
- 3D가 작동하지 않아도 사용자가 빈 화면을 보지 않음
- 개인정보 원문이 다른 그룹원이나 분석 도구에 노출되지 않음
- 첫 방문, 등록, 초대, 결제, 재방문을 측정할 수 있음

## 24. 구현하지 말아야 할 잘못된 방향

- 새로운 아이디어가 생길 때마다 P0보다 먼저 구현하지 않음
- 3D 효과가 계산 의미보다 앞서지 않음
- 행성 고리 수를 단순 그룹 가입 수로 사용하지 않음
- 먹구름을 `나쁜 사람`의 영구 표시로 사용하지 않음
- 반투명 표현을 초대 미확인과 유료 잠금에 동시에 사용하지 않음
- 그룹 초대 또는 참여 자체에 높은 결제 장벽을 두지 않음
- 무료 그룹 참여로 개인 은하 유료 등록을 완전히 우회하게 만들지 않음
- AI가 계산 근거 없이 결과를 창작하지 않음
- 출생정보를 그룹원에게 기본 공개하지 않음
- 결제 결과와 토큰 잔액을 브라우저 저장만으로 관리하지 않음
- 모든 기능을 단일 HTML에 계속 추가하지 않음
- 구독 상품의 가치가 정의되기 전에 월 구독을 억지로 붙이지 않음
- 일반 운세 콘텐츠를 무분별하게 추가해 관계형 사주 정체성을 흐리지 않음

## 26. 최종 제품 판단 기준

사주은하의 경쟁력은 행성이 예쁘게 보이는 것만으로 완성되지 않는다. 아래 질문에 좋은 답을 줄 수 있어야 한다.

> 그래서 이 사람과 나는 어떻게 해야 하는가?

> 이번 달에는 누구에게 다가가고 무엇을 조심해야 하는가?

> 내 그룹에서 지금 나에게 가장 도움이 되는 사람은 누구인가?

제품의 우선순위는 항상 다음 순서를 따른다.

1. 계산의 신뢰성
2. 관계 결과의 이해도와 행동 가능성
3. 초대와 개인정보 보호
4. 결제와 토큰의 정확성
5. 월별 재방문 이유
6. 3D 시각 효과의 풍부함

현재 사주은하는 독창적인 콘셉트와 작동하는 데모를 확보했으나, 계산 검증·서버·회원·개인정보·결제·재방문 구조가 남은 상용화 이전 단계다. 방향을 바꾸기보다 첫 번째 출시선을 확정하고, 이 문서의 P0부터 작은 단위로 완료해야 한다.
